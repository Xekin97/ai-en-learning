# 生成中与完成后的词义和正文视觉一致性

## 发现的问题

用户在当前 UAT 反馈：“嗯，效果可以，但有地方不对，能不能统一一下预生成时和生成完成后的元素样式，比如像单词释义这块，完全长得不一样”。这是定向修正请求，不是整体 UAT 通过。

## 证据与来源

- GenerationWorkspace.vue 生成中使用 m003-plan-uses / m003-plan-use，完成后使用 study-resources / resource-grid / resource-card。
- theme.css 两套选择器分别定义固定双列、12px 间距、带边框卡片与 auto-fit、22px 间距、无同等卡片表面，标题/词条字体也不同。
- PAGE-204 / PAGE-216 共用 GenerationWorkspace；PAGE-212 的预览还有独立词义结构，应由设计检查同类落差后明确最小适用范围。
- 已批准基础：M002 正式视觉、UI09-R3 阅读列与暂定词义/用法/场景保留至最终 valid 整包；现行 UI10-R1.1 无关模型弹窗保持。

## 建议变更

- CONFIRMED / USER-M003-GENERATION-VISUAL-CONSISTENCY-20261013：统一生成前中后相同元素的视觉，尤其词义。将现有卡片、字体、行距、间距和响应式规则收敛为一致实现。
- 设计角色先给出最小正式设计修订及精确前端接点；前端实现并由 QA 做样式/行为复验后更新当前 UAT3014 供用户验收。
- 沿用现有设计系统，不引入新业务、新文案承诺或全站重设计；暂定内容仍暂定，最终释义仍来自最终结果；无需后端、模型、数据库、收费或流式协议变更。
- 本地浏览器检查使用合成数据；无新增真实模型调用。当前 UAT DB、已保存配置和旧 UAT 不变。

## 不变更的影响

同一生成任务状态变化时，相同学习内容视觉风格突变，降低连续阅读和组件一致性。
