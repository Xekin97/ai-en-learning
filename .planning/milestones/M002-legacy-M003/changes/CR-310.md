# 完成后直接编辑配置，再次生成时确认放弃未收录结果

## 发现的问题与用户确认

用户在 UAT 反馈生成后选词、配置和生成按钮被锁住。代码 GenerationWorkspace 的 busy 包含 valid，必须到结果底部先手动放弃后才能继续。用户明确纠正：“不应该这样，不需要锁配置或者让用户点击放弃，而是用户下一次生成时反馈用户旧数据不保存会被永久放弃这类的提醒”。

CONFIRMED / USER-M003-REGENERATE-CONFIRM-20261013：成功完成后允许编辑下一次选词和配置，不要求先点独立放弃按钮；再次生成时如有尚未收录的旧结果，先提示继续会永久放弃该结果，用户确认后再生成。取消确认须保留结果与新编辑的配置。此规则适用于普通游客/登录用户；预设试用的既有只读配置不因本条成为可编辑业务。
