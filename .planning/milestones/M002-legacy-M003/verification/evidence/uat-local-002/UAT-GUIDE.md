## 快速验收

### 1. 游客与普通生成

在造文台选择：

- AI 模型：`UAT 合成｜成功`
- 场景：故事
- 长度：简短
- 释义语言：中文
- 单词：`machine`、`preclude`、`interim`、`juvenile`、`retroactive`

点击“开始生成”。应依次看到：

1. 真实 Plan 区域，包含场景和各词用途；
2. 连续出现的正文草稿；
3. 最终正文、标签、五个词义/提示项；
4. 游客的登录/收藏入口，或已登录用户的收藏按钮；
5. 已登录账号额度只减少一次。

准备冒烟已用 Basic 执行一次，所以 Basic 当前余额为 99；Pro 仍为 100。

### 2. Pro 增强路径和 Q02

用 Pro 登录，生成选项应显示 Pro。测试账号后台已配置内容审校开启、返修上限为 1；用户页面无需显示审稿轮次或上限。

选择 `UAT 合成｜审校故障 Q02` 并使用同一组参数。预期系统保留最后一份有效正文，在最终结果上显示审校未完成提示，并且一次业务请求仍只扣一次额度。

### 3. 管理员参数读回

用 Admin 登录，打开 <http://127.0.0.1:3014/admin/models>：

1. 找到 `UAT local synthetic provider`，点击“编辑服务商”；
2. 找到 `UAT 合成｜参数快照可编辑`，展开“高级选项”；
3. 修改高级 JSON，保存后重新打开，确认读回一致；
4. 输入错误或重复键 JSON，确认原文保留、错误字段聚焦，且没有保存；
5. 修改后尝试取消、Esc、标题关闭或背景关闭，确认先出现放弃确认；
6. 选择继续编辑时回到父弹窗中触发确认的控件，放弃或保存后回同一服务商的编辑按钮。

保存配置不会测试连接，也不会调用 provider。不要在本步骤点击“测试模型”。
