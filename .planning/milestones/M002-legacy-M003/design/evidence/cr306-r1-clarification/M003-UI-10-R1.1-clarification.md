Sources: `technical/api/administration.md#api-306`, `technical/api/presets.md#api-306-preview`, and `technical/fixtures/cr306/errors.json` boundary fixtures.

Clarified contracts:

- `{}` sends no custom parameters; blank text is invalid JSON.
- The 16 KiB limit applies to normalized compact-object UTF-8 bytes. Invalid/incomplete JSON displays `—` for compact size; raw whitespace is not treated as compact bytes.
- `422 too_large` is field-associated. `413 request_too_large` is form-level when no field is supplied, retains all edits, and is never attached to the first model by guess.
- Explicit probe has a fixed 256-token output maximum and can incur a small charge. Save makes zero model calls and does not require probe.
- Probe stale means the old test no longer matches the current draft; direct save remains legal.
- Model-configuration changes affect only newly accepted request snapshots. Existing in-flight/completed runs remain unchanged; PAGE-212 readiness expires only when its local preset draft or preview configuration changes.

The immutable accepted R1 package is `../cr306-r1/M003-UI-10-R1-source.tar.gz`. This directory contains only the R1.1 clarification, targeted check, and incremental recovery package.
