# M003-UI-15 交互与 Motion

## I501 分类入口与导出

导入/导出只作用于当前类别，列表筛选、分页和成长当前 tab 不改变文件范围。导出打开 modal；普通模型导出默认无 Key。勾选“包含 API 密钥（加密）”后显示文件口令与确认，两次一致才准备结果。口令输入不回显、不写入状态演示日志；设计的“准备下载”只给本地模拟结果，不创建真实文件。

## I502 导入状态机

```text
file → decrypt(models encrypted) → reading → preview → confirm → submitting
  ├─ mismatch / wrongpass / missingkey / fields / blocked
  ├─ target changed → stale → re-preview
  └─ response lost → unknown → check result | read current → known result
```

`file / decrypt / reading / preview / confirm` 均无写入。改变文件、类别、凭据处理或目标 revision 立即丢弃旧 preview/ack。非模型文件可从 file 直接进入校验/preview；模型示例必须经过 decrypt。修正错误需重新选择文件或重新预览，不能在 modal 临时补 Key/依赖。

## I503 预览和依赖阻止

预览固定先显示新增/更新/移出/不变，再按三组列出每个变化项的安全身份、可读名称和业务字段变化，随后显示类别影响、凭据完整性或目标生效日。三组默认展开，可单独折叠；空组仍明确显示 `0 / 无`。字段值解析后的应用结果直接显示在对应项下：可选字段省略可产生 hostname 自动连接名、无说明、未设置最大输出 token 或无道具；道具单语言为空按另一语言回退；计划不限额必须来自必填额度的显式 `null`，省略会拒绝。任何情况都不能从目标旧配置继承。计数是本次预览结果，不从当前分页推算。跨类别引用和道具历史保护用阻止态显示来源类别/配置和被引用对象；无“跳过”“自动解除引用”“仍然导入”动作。

## I504 最后确认与提交

确认页再次显示整类警告、计数和影响，并把移出组排在第一位且默认展开；没有移出项也明确显示 `0 / 无`。新增和更新组可展开复核。管理员需勾选确认句，按钮文案为“替换此类别全部配置”，不使用普通“保存”。提交后进入 `submitting`：按钮禁用，重复点击无效，Escape/背景点击不能宣称取消。技术实现再次校验权限、目标基线和依赖；设计不规定 API 或事务实现。

## I505 成功、失败与未知结果

成功显示类别、数量和生效说明，并明确其他类别与运行历史未改。响应丢失进入 `unknown`，只显示“查询本次结果”和“读取当前配置”；两者均从权威状态收敛，不能提供盲目“重试替换”或“回滚”。权限过期、校验/提交失败保留安全错误，不泄露文件或秘密内容。

## I506 modal、取消与焦点

打开 modal 记录发起按钮，初始焦点进入首个可操作项；Tab/Shift+Tab 留在 modal。预提交状态的 Escape、关闭键和背景点击关闭且无变化，焦点回到发起按钮。`reading/submitting` 不关闭；`unknown` 必须先查询，不显示关闭即撤销的暗示。长内容只滚动 `.dialog-body`，标题和 footer 留在视口。

## I507 字段说明与错误定位

文件态显示当前类别最重要的必填/可选说明；preview 在对应配置项旁显示 `missing/null/false/0/empty` 解析后的应用结果，完整表始终链接产品字段表。错误顺序为类别 → 配置项安全名称 →业务字段 → 原因。实现把变量作为文本，禁止拼接秘密、口令、原始请求或堆栈。

## I508 Motion

modal 进入沿现有 `240ms / var(--ease)` 轻微淡入/上移；状态内容在同一 modal 内即时替换，不用进度百分比或假步骤动画。读取/提交使用无进度承诺的 spinner；成功/错误图标即时出现。状态切换时取消旧 timer/请求回调，迟到结果不可覆盖新文件或新类别。

## I509 reduced motion

`prefers-reduced-motion: reduce` 时 modal 和内容无位移动画，spinner 停止旋转但保留“正在…”文字与 `role=status`。业务时序、禁用状态、焦点和提交互斥不变。
