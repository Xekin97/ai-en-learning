# M003-UI-14 发音交互与 Motion

## I401 单一播放状态机

每个可见 DATA-401 词条有 `idle → preparing → playing → complete` 主路径。按钮激活后立即进入 preparing 并显示当前词；词典成功进入 `playing / dictionary`。缺词、空音频、请求/解码/播放失败或技术阶段定义的有限超时，只尝试一次浏览器路径；成功进入 `playing / browser` 并显示真实来源。

完全失败进入 `error`，显示当前词和“重试发音”。错误只属于发音，不禁用选词、生成、保存或阅读。完成后按钮可重播；播放中再次点击先停止当前实例，再从头开始同词同口音。

原型的等待/播放时长是设计 harness 固定值，不进入实现。生产 `preparing` 的上限、voices 等待与浏览器手势策略由 OPEN-403 定义。

## I402 单一活动目标与竞态

页面级控制器只保留一个 active target（词、来源、口音、request epoch）。点击 B 时同步停止 A 的 audio/speech、取消能取消的请求、让 A 退出 preparing/playing，再启动 B。A 的迟到响应必须比对 epoch；不匹配即丢弃，不更新状态、不播放。

入口因选词删除、计划切换、内容替换而卸载，或发生 route/pagehide 时，执行相同取消。状态最终回到可重试的 idle/complete/error，不留下队列。生成流、保存和页面阅读使用各自状态，不等待发音 promise。

## I403 口音与来源

- 只有一种可靠可用口音：仅显示播放键，不显示菜单。
- 英/美均可靠可用：播放键旁显示菜单触发键，菜单只列真实项；Escape 关闭并把焦点还给触发键。
- 地区未知：显示中性“播放发音”，不标英/美。
- 用户已选英音而该音频失败：优先尝试同口音浏览器声音。若只剩美音，进入 `accent unavailable`，显示“使用可用英语声音”；只有用户点击后才播放美音。
- 词典录音与浏览器朗读的状态文案不同；合成语音不标为词典录音。

## I404 手势、声音延后与失败

浏览器拒绝异步朗读且要求新手势时，停止自动尝试，显示“再次点击播放”。该动作从浏览器路径继续，不重新循环失败词典。voices 尚未就绪允许在 OPEN-403 的界限内等待；无英语声音或不支持 speechSynthesis 进入明确失败。重试开始新 epoch。

## I405 PAGE-401 独立动作

搜索候选每行的播放与添加是相邻独立按钮。组合框 active option 的 Enter 仍表示添加；Tab 可离开输入并依次到播放/添加。已选词 token 顺序为词、播放、可选口音、删除；删除当前播放词时先取消。随机、添加、删除均不自动播放。

## I406 PAGE-402/403 局部状态

计划/完成 GenerationVocabularyList 与已收藏学习卡都在标题右侧放播放组。状态槽位于当前条目的释义之后；出现时可增加卡片高度，但不得覆盖相邻词或改变文章滚动位置。计划到完成替换导致当前入口消失时先取消。正文 mark 始终不是发音入口。

## I407 Motion

- 菜单：180ms，`cubic-bezier(.2,.72,.2,1)`，opacity + `translateY(-4px)` + scale(.98) 到稳定位置。
- 状态：160ms，同 easing，opacity + `translateY(-2px)`；错误/取消即时改变语义，动画不能延迟状态。
- preparing/playing 图标以 920ms pulse 提示活动；playing 外环 1150ms 单向扩散。`aria-pressed` 与文字同步，动画只作补充。
- 新播放取消旧播放为即时状态切换，不对声音做交叉淡入淡出，避免重叠。
- `prefers-reduced-motion: reduce`：菜单/状态直接出现，图标不 pulse、无外环；状态文本和取消规则不变。

## I408 演示控制边界

正式稿底部 `<details>` 与原型侧栏为设计 harness，默认收起/与产品页面分离。它们切换确定性 scenario，不连接真实词典、浏览器 speechSynthesis、造文、登录或额度。前端不得复制这些演示控件到产品。
