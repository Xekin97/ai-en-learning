# M003-UI-14 响应式与可访问性

## 视口与布局

| 范围 | 正式设计规则 |
|---|---|
| ≥901px | 沿用现有 282px 设置侧栏 + 主区；正文内部最大 760px。发音只占词标题右侧，不改变工具台主列。 |
| 761–900px | 设置区进入主列；词义仍按现有可用宽度决定双/单列。 |
| ≤760px / 390 基准 | 页面容器左右 12px，设置折叠外观、词义单列、播放键 44×44。已选词按通用单列结构占满可用行宽；word label 可收缩并在必要时换行，不用 ellipsis 隐藏学习对象。口音菜单固定在 viewport 底部左右 12px。 |

中文和英文都需检查。英文长状态允许换行；来源/错误不能造成横向滚动。实现遇到长词时优先让 token 占满一行或让词文本换行，禁止截断词本身，也不得缩小触控目标。当前 390px 定向复验覆盖不带菜单 `communication` 与带菜单 `pronunciation`：词文本 client/scroll width 分别为 `110/110px` 与 `99/99px`，无需 tooltip 即可完整读取；所有相邻控制仍为 `44×44px`，页面横向溢出为 `0`。

## 键盘与焦点

1. 播放键使用原生 button；Tab 可达，Enter/Space 触发。可访问名称使用 `pron.playWord`，必须含当前词。
2. 候选行的播放和添加是两个焦点目标；播放后不移动组合框选择、不添加词。添加后的焦点恢复沿用 WordPicker。
3. 口音触发键有 `aria-expanded`；菜单项为 button/菜单项。Escape 关闭并回焦触发键；选中后回到播放控制或按实现立即开始所选口音。
4. 新目标替换旧目标时焦点留在用户点击/键入的新控件；迟到响应不得抢焦。
5. 错误后的“重试发音”“再次点击播放”“使用可用英语声音”在当前状态卡中紧接说明，可通过 Tab 到达。
6. Skip link 只在键盘聚焦时可见；常规截图和鼠标流程不常驻。

## 屏幕阅读器与状态

- 每个播放键的名称含单词；重播状态用 `pron.replayWord`。纯图标 `aria-hidden=true`。
- 当前条目状态槽使用 `role=status aria-live=polite aria-atomic=true`。准备、来源、失败按状态整句播报，不把正文或逐帧动画放进 live region。
- 播放中同时设置 `aria-pressed=true`。错误通过文字和可操作按钮表达，不只靠红色；playing 通过 pressed、状态文字和图标表达，不只靠动画。
- 口音项可见文本为英音/美音；中性来源不虚构地区。来源文本在完成后保留，直到新动作或入口移除。
- 取消旧播放时旧条目可礼貌播报一次“已停止上一条发音”；不会播报技术堆栈、URL 或内部错误码。

## 触控与 Motion

- 390px 播放控件、菜单项和关键后续动作目标至少 44px；桌面圆形播放键 40px，周围不与删除/添加重叠。
- 播放与删除/添加之间保持至少 4px 视觉间隔和独立 hit target；不能靠事件冒泡让一个触控同时触发两项。
- reduced motion 规则见 [interactions.md](interactions.md#i407-motion)：状态立即可辨识，业务时序不变。

## 内容与语言

英语词、短语和文章保留 `lang=en`；中文/英文界面根语言准确切换。固定文案来自 `copy.json`，变量 word 作为文本渲染。发音不可用不移除词义/用法，也不改变上下文释义。
