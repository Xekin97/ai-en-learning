# CR-313 后台配置按类别导入导出

管理员可以把一种运营配置导出为文件，在目标环境预览后，用文件中的完整配置替换所选类别。目标是减少重复手工配置，同时让管理员明确知道将替换什么、哪些依赖或既有用户会受影响。不是数据库备份、跨环境同步或运行数据迁移。

<a id="scope"></a>

## 确认、现状与边界

| 条目 | 分类 | 当前结论 |
| --- | --- | --- |
| S501 类别 | CONFIRMED | 模型配置、计划配置、道具定义、成长规则（签到、等级、成就）分别导入导出；用户明确排除预设短文与公告。 |
| S502 替换 | CONFIRMED | 导入替换所选类别的全部配置，不是合并或只新增。文件未包含的旧配置不能悄悄保留为当前活动配置。 |
| S503 凭据 | CONFIRMED | 提供管理员显式选择、将 API 凭据随模型配置加密导出的路径；普通导出不携带密钥。未确认具体加密格式/算法或保管机制。 |
| S505 必填与引用保护 | CONFIRMED | Q313-01：模型导入不含 API Key 则整次失败；Q313-02：移除配置破坏跨类别引用则整次阻止并列依赖。用户要求明确必填/非必填，详见下方字段表。 |
| S504 研发范围 | CONFIRMED | 本需求继续在 M003，由产品先定义，再交设计和技术；M003 整体未批准收尾。发音 PRODUCT11 已接收，UI14 仍待审，不因本稿重开或替代。 |

来源：[CR-313 原始需求与答复](../changes/CR-313.md)、[本轮精确答复](../reviews/evidence/cr313-product-revision-108-r1/clarification.json)、[产品进入门禁108](../reviews/cr313-product-entry-108.md)。下述新交互/文件行为为 **PROPOSED** 待审建议；明确引用旧批准条目的规则是继承约束，不是本轮重新替用户决策。

不包括账户、角色、用户基础计划分配、积分/经验余额、背包实例、发放/兑换/使用流水、成就/等级领取记录、学习内容、预设、公告或其他运行历史。不增设定时备份、队列、批量跨类别事务、密钥保险库、自动补依赖或通用回滚平台。管理员先导出目标环境现状可作为人工留存；再次导入仍需全部校验，不承诺无条件恢复历史运行状态。

当前代码已有分类保存、revision 冲突、模型移除影响预览、成长生效规则；尚无本次分类导入导出闭环。代码只用于确认现状，不能替代产品授权。只读依据见末尾；本稿不定义 API 字段、数据库表、加密算法或身份映射实现。

## 数据与类别边界

所有资产仅管理员可操作。文件含配置而非运行历史；导出不会使目标环境取得源环境的用户权限、用量或发放记录。

| ID | 类别 / 内容 | 整类替换的业务边界 |
| --- | --- | --- |
| DATA-501 | 模型：连接名称、协议/服务地址、模型标识、名称说明、参数、输出/启用配置；凭据仅 S503 可选路径 | 替换当前模型与连接配置，移出的模型不能继续用于新生成。为历史短文/库存核对而保留的退役身份不算活动配置；不重建历史批次，不复活退役身份冒充新配置。跨类别移除影响见 Q313-02。 |
| DATA-502 | 四个固定计划：访客、普通、Pro、Plus 的优先级、模型范围、额度、词数/长度、内容审稿/返修配置 | 继承 M002 CAP-103：不能创建、删除、重命名固定计划，文件必须完整包含四计划且合法。替换不重置已用次数、不延长体验、不改用户基础计划；在途请求保留原接受快照，新请求按新配置。 |
| DATA-503 | 道具定义：现有四类道具的双语名称/说明、价格、上下架、启用期限、作用参数与计划/模型引用 | 不导出是否发放过、库存或来源流水。目标历史独立校验：继承 D2-68，遗漏有发放历史或奖励引用的道具将阻止整次导入；不能删历史，也不能静默保留旧活动定义。已存在道具类型不可改变；引用/身份须准确，不能按显示名称猜测同一对象。 |
| DATA-504 | 成长：签到/掌握经验规则、等级门槛/奖励、四类成就档位及双语内容/奖励 | 不导出成长起算时间、个人达成/领取或签到历史。签到沿目标环境下一学习日生效，当天及历史规则仍供原结算。等级/成就当前配置完整替换，文件未含档位退出当前规则；已有达成/领取事实保留，退役档位不能继续作为活动规则。 |
| DATA-505 | 分类配置文件及必要的类别、格式版本、内容范围、引用信息、是否包含加密凭据的描述 | 每次一类；非选中类别不随文件暗中写入。普通文件无真实 Key，掩码/“已配置”不能当作密钥导入。文件是管理员下载的副本，系统不承诺召回或自动保管；无新长期上传文件库需求。 |
| DATA-506 | 本次替换预览、目标配置基线、依赖/影响、提交结果 | 仅本次操作用；选文件/预览不改变生效配置。改变文件、类别、凭据处理或目标配置后旧预览失效。目标 revision 由目标环境判定，源文件版本不能覆盖目标并发保护。 |

继承规则原文：[固定计划 CAP-103](../../M002/product/abilities.md#cap-103)、[计划体验 CAP-216](../../M002/product/abilities.md#cap-216)、[道具/历史 CAP-217](../../M002/product/abilities.md#cap-217)、[签到 CAP-211/212](../../M002/product/abilities.md#cap-211)、[等级/成就 CAP-214](../../M002/product/abilities.md#cap-214)。计划卡仍读取目标计划最新权益，模型卡保留发放时模型集合与时长，失效模型不可借旧卡调用；下架积分沿现有动态值规则。导入不得抹除这些差异。

PROPOSED：成长导出说明当前与已设定的待生效签到值；导入将源环境最新运营意图（有待生效值时采用待生效值，否则采用当前值）设为目标下一学习日规则，预览明确所取来源与目标生效日，不照搬源环境绝对日期或历史签到规则。文件没有待生效值表示不带源环境待生效版本，不能继承目标原待生效值；提交以本次明确选定的完整值替换目标下一学习日配置。等级变化沿既有降级、暂缓未领奖励、重新达标与已领奖不重发规则；成就达成保留，停用/移出当前规则后不得继续领取该停用档奖励，不追补历史差额。

## 四类配置的必填与可选字段

以下是**导入业务字段表**，不是文件/API 字段名或序列化 schema。依据现有管理台与后端验证形成 PRODUCT12-R1 的 PROPOSED 细化；Q313-01 的密钥必填和 Q313-02 的依赖阻止已由用户明确确认，不能由此表放宽。必填值即使管理台新建表单有默认值，文件也必须明确提供，导入不得从目标旧配置补齐。

| 通用情形 | 处理规则 |
| --- | --- |
| 必填项缺失或 `null` | 拒绝整次导入；仅表中明确允许 `null` 的业务含义例外。不能把解析器默认值当成用户填写。 |
| `false`、`0` | 都是明确的值，不是缺失。关闭状态必须明确写出 `false`；数值 `0` 是否有效逐字段判断，不自动替换为默认值。 |
| 空字符串/纯空白 | 必填文本不满足要求；可选文本按表清空或生成明确回退值。凭据不做自动拼接/猜测，空白不是Key。 |
| 空数组/空集合 | 与“未提供”不同；仅允许集合为空的字段可接受。选中类别的集合本身必填；明确空集合触发清空预览及全部依赖/历史保护，不能跳过该类别。 |
| 可选项省略 | 仅采用下表写明的“无/清空/推导”语义，**不继承目标旧值**。业务上明确选择无奖励、无限额度等也要能与必填项缺失区分。 |
| 类别、文件版本、条目身份与引用身份 | 必须足以确定所选类别、支持版本、每条配置身份及准确依赖；不能仅凭显示名猜对象。具体标识与跨环境映射交 TECH-501，不要求用户填写目标数据库ID。 |
| 当前版本、创建/更新时间、已发放标记、影响计数、学习日/成长起算及秘密掩码 | 属于源信息/目标校验事实，不是可导入的运营写入字段；不能拿源值覆盖目标事实、绕过保护或代替Key。 |

### 模型配置（DATA-501 / PAGE-501）

| 业务字段 | 必填性 | 空值、范围与缺省含义 |
| --- | --- | --- |
| 连接集合及其模型集合、每个模型的连接归属 | 必填 | 明确完整集合；模型必须指向包内明确连接。无模型不等于漏给模型清单；空类别仅按 CAP-502 的合法清空规则处理，有连接就须逐条满足Key必填。 |
| 连接协议 | 必填 | 当前支持 OpenAI Chat、OpenAI Responses、Anthropic Messages；缺失不猜测默认协议。 |
| 服务基础地址 | 必填 | 非空、现有允许的 HTTP(S) 基础地址；不含用户密码、查询或片段，不把具体聊天/响应/消息请求路径当基础地址。沿既有格式校验。 |
| 每个连接的 API Key | **必填，CONFIRMED** | 包中加密内容须可完整解密，Key非空且通过本地格式校验；缺失、空白、`null`、掩码或“已配置”都失败。含停用连接/模型也必填，不复用目标Key，不提供导入时补填。合法输入不代表供应商校验通过。 |
| 连接显示名称 | 可选 | 省略/`null`/空白时按所填服务地址主机名生成名称；提供时不超过既有200字符限制，不继承目标旧名称。 |
| 精确上游模型标识 | 必填 | 非空，保留大小写/斜杠等内部字符，不接受首尾空白；同连接内不可重复，沿既有500字符限制。 |
| 模型显示名称 | 可选 | 省略/`null`/空白时沿现有规则使用模型标识的前200字符；提供时不超过200字符，不继承目标旧名。 |
| 模型说明 | 可选 | 省略/`null`/空白表示无说明并清除目标旧说明；有内容时不超过1000字符。 |
| 最大输出 token 限额 | 可选 | 省略/`null`表示本产品不显式设置此项；填写须为1～1048576的整数，`0`/空字符串非法。不继承目标旧限额，也不把未设置解释为供应商无限制。 |
| 结构化输出模式、启用状态 | 必填 | 明确现有允许模式及启用/停用；`false`是有效停用，缺失/`null`不是停用。模式遵循所选协议的当前支持范围，不能因前端新建默认而省略。 |
| 自定义请求参数 | 必填 | 必须明确提供合法参数对象；空对象 `{}` 表示不附加参数，缺失/`null`/空字符串/数组均拒绝，不保留目标旧参数。沿现有受保护字段、大小与嵌套校验，不容许混入Key、地址、消息或覆盖受保护编排。 |

连接名/模型名可选依据现有自动命名行为；其他管理台默认的协议、启用状态、输出模式与 `{}` 参数对象不因此成为可省略项。普通不含Key导出可用于查看/留存非秘密配置，但不能直接完成模型替换导入；需重新导出含加密Key的包。

| 成就名称、称号 | 各自必填；每项中英文至少一项非空 | 单语言可无值，按既有另一语言回退；各版本最多200字符，不保留目标旧译文。名称或称号两语言均空则失败。 |
| 成就说明 | 可选 | 两语言都可无值；省略/`null`/空白表示清空对应说明，不继承旧文；有值每版本最多2000字符。 |
| 成就积分奖励、经验奖励 | 每档必填 | 非负整数，明确 `0`允许；关闭成就也不能省略或以 `null`代0。 |
| 等级/成就奖励中的道具选择 | 可选 | 省略/`null`表示无道具奖励，清除目标对应配置引用，不清除已发库存。选择时须为存在且奖励可用的道具；空字符串/空数组不是有效道具身份。 |
| 等级/成就奖励中的道具数量 | 有道具时条件必填 | 有道具须1～2147483647整数；无道具时可省略或明确0，含义均为不发道具，正数/`null`拒绝。选择道具而漏数量不得自动补1。 |

积分、经验、价格等金额类字段均按现有非负整数与可表示范围校验，不接受小数、负数或把缺失转换为0；它们在文件中的编码方式交技术定义。原等级/成就达成、领奖、库存等事实不在上述表中，不可随文件重置。

<a id="field-errors"></a>

### 字段错误与确认反馈

读取/解密后按“类别 → 配置项（名称/安全身份）→ 业务字段 → 原因”定位错误，例如“模型连接乙：缺 API Key，请重新导出含加密Key的包”“Pro：缺少返修上限，关闭时也须明确0”“道具丙：名称或说明至少提供一种语言”“等级2：已选奖励道具但缺数量”。错误摘要可跳到相应项，不回显密钥/口令、完整秘密字段或原始请求。

任何必填/条件必填错误整次拒绝；可一次列出已能可靠发现的多项错误，不能先写入合法部分。可选默认值在预览展示应用后的明确结果（如自动名称、无说明、无道具），不能将“已匹配目标旧配置”作为省略值的来源。修正文件后重走预览；不新增导入时临时补密钥路径。

<a id="capabilities"></a>

## 操作能力与结果

### CAP-501 分类导出

管理员在当前类别选择导出，显示类别及包含范围；模型类别可主动勾选“包含 API 密钥（加密）”，默认不勾选。生成的是所选类别的完整一致配置，不是当前筛选页或分页结果。导出仅准备下载文件，不保存配置、不调用模型验证连接、不改变用户权益；失败可重试，不产生半份有效文件。

若配置含其他类别引用，文件携带准确识别依赖所需信息，不偷带整类依赖。旧运行记录及历史退役对象不是配置导出内容。文件可供同环境恢复配置或另一环境导入；实际导入须能准确匹配/建立引用，无法确认的映射要拒绝，不能按相似名称自动串接。

### CAP-502 导入校验与替换预览

选择类别 → 选择文件 → 必要时解密 → 校验 → 展示替换预览；这些步骤均无配置写入。预览说明新增/更新/移出数量与可定位的配置项、缺失依赖、无法删除原因、各导入连接的密钥完整性及缺失错误、对计划/预设/道具的影响及生效时间。空集合必须明确显示“清空本类别活动配置”的结果，仅在该类别允许且没有保护条件时才能进入确认；固定计划或缺少必需成长规则的空文件拒绝。

类别不匹配、格式不支持、损坏、重复/冲突身份、字段非法、目标缺失必要依赖、无法确认引用、口令错误均明确失败，保留目标原状。错误定位配置项/原因，不回显 Key、口令或秘密字段原文。目标缺失依赖时提示先处理相应类别；不自动新增依赖、不跨类导入。旧版格式兼容不默认建设，沿首版兼容政策显式拒绝未支持版本。

### CAP-503 确认、整类提交与结果

只有通过校验且预览仍有效才能确认“替换此类别全部配置”；确认界面明确移除项与影响，不能用普通“保存”掩盖整类替换。提交时再次检查管理员权限、目标基线、引用与历史保护条件。一次所选类别替换全部成功或不生效，不留下部分替换；运行历史均保留。业务上要求原子结果，具体实现由技术角色定义。

取消预览/离开确认前不改变配置。提交已发出后不能声称关闭弹窗就撤销；结果未知时显示“结果待确认”，读取结果/当前配置后再判断，不盲目重放。重复点击不重复提交或触发生效副作用。并发配置或相关引用/发放历史改变时，旧预览失效，重新预览确认；不静默覆盖另一管理员的更改。

成功结果说明所选类别已替换、数量/生效时间；模型类别必须已具备本次文件要求的全部凭据，不能出现“成功但待补Key”的结果。刷新读取与预览一致。只替换选中类别。按 Q313-02，移除项仍被其他类别引用时整次阻止，列出来源类别、被引用项及阻止原因，管理员先处理依赖再重试，不联动修改未选类别；不把依赖保护变成“跳过失败项，其他成功”的合并导入。

### CAP-504 可选加密凭据文件

普通导出不含真实凭据；勾选时把凭据随配置加密导出，不提供明文密钥文件。PROPOSED：管理员为本文件设置并确认口令，导入时输入同一口令，口令自行保管；不建设找回/托管功能。文件与口令分开保管的短提示属于必要操作说明，不能把设置文件口令误作修改管理员登录密码。

普通列表、预览、结果、日志、错误与文件名均不暴露明文密钥或口令；未获管理员权限不能下载含密钥文件或解密后提交。加密完整性、抗篡改、口令强度、临时材料清理与大小限制由技术方案落实。错误口令/篡改文件不退回明文或部分导入。加密文件解密后仍须全部配置校验；能解密不等于可信或可直接应用。

**CONFIRMED / Q313-01：每个导入连接都必须在本次文件中包含可解密、非空且满足现有本地格式校验的 API Key；任何一个缺失就整次导入失败。** 当前支持的三种协议均适用，即使连接/模型停用、目标已有Key且地址协议相同也不能绕过。掩码、“已配置”状态、空白或 null 不是密钥；不能保留目标Key、清空后补填、禁用后放行或在导入过程中临时补Key。普通不含Key导出仍允许，但这类文件不能直接完成模型替换导入；错误明确提示缺少哪个连接的密钥，并引导回源环境重新导出含加密Key的完整包。若源配置本身缺Key，先在原有模型管理完成配置，再重新导出。

“有效输入”仅指必填、解密完整性和本地格式检查；不证明提供方接受该Key，也不自动发起连接探测/模型调用。原Q313-01保留目标Key/清空后补填建议与Q313-02联动移除建议均已撤销，不能成为技术默认。

<a id="ai"></a>

## AI 与既有运行边界

本需求没有新 AI 输入输出，不自动翻译导入内容、不推断模型能力、不生成/修复配置、不自动测试 Key 或调用模型。模型自定义参数沿现有合法性规则，不能借文件塞入凭据/任意消息覆盖受保护的配置边界。模型启用状态是配置，不等于连接已实测成功。计划内容审稿/返修配置按原权益生效；导入不改变在途稿件快照、用户额度或学习内容。

QA 验证功能、契约、权限、秘密不外露及替换一致性，不做文章质量评估。真实 UAT3015/4174、已接受 CR311/312 与发音 UI14 均不由本阶段刷新。
