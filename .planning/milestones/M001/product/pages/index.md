# M001 页面与能力映射

CR-040 仅同步学习内容语义，范围与历史版本见[当前修订入口](../overview.md#cr040-revision)。释义统一遵循 [AI 行为 §3.3](../ai-behavior.md#original-entry-meaning)；不新增控件或页面文案要求，不重做已批准 UI。

## 1. 导航结构

```text
公开/学习者区
PAGE-001 首页
├─ PAGE-004 造文
├─ PAGE-002 注册 ─┐
├─ PAGE-003 登录 ─┴─ 认证后返回原意图或学习者首页
├─ PAGE-005 学习记录 ─┬─ PAGE-006 批次详情
│                    └─ PAGE-008 复习过程（单批次直接复习）
├─ PAGE-007 复习范围 ─ PAGE-008 复习过程
└─ PAGE-009 账号设置

管理员区（与学习者共用 PAGE-003 登录，无独立仪表盘）
├─ PAGE-101 OpenRouter 与模型
├─ PAGE-102 组别配置
└─ PAGE-103 用户管理（含只读学习库查看）
```

管理员登录后只进入管理员区，不提供学习者功能。访客直接访问受限页面时保留明确意图并前往登录；登录后回到可执行的目标页。造文结果承接使用 PAGE-004 与 PAGE-002/PAGE-003 的专用返回流程。

### 1.1 全局界面语言责任

- PAGE-001 至 PAGE-009、PAGE-101 至 PAGE-103 都提供 CAP-021，并读取或更新 DATA-018。
- M001 首发界面语言为 `zh-CN` 与 `en-US`。语言入口属于全局用户/管理员壳层，不新增独立语言设置页面。
- 切换后当前页面、导航、表单、状态、错误、对话框和系统反馈使用同一界面语言，同时保留当前路由与任务状态。
- 品牌按当前界面语言单一展示：`zh-CN` 只显示“词涟”，`en-US` 只显示“WordWeave”；未来任何非中文界面统一显示“WordWeave”。该规则覆盖全部页面和断点；英文学习材料和按释义目标语言生成的内容不因界面切换被翻译或改写。

## 2. 用户页面

### PAGE-001 首页

- **角色**：访客、学习者。
- **目标**：用最短路径解释“选词—AI 场景短文—保存复习”的价值，并进入主要任务。
- **数据**：读取 DATA-018；无其他私有 DATA。
- **能力**：CAP-001、CAP-003、CAP-021。
- **主要区域**：与当前界面语言一致的单一品牌名称与价值说明；“立即学习”“开始复习”“学习记录”主入口；登录/注册或当前账号入口。
- **关键状态**：访客状态、已登录学习者状态；管理员认证态不落在此页。
- **离开路径**：造文、复习范围、学习记录、登录、注册、账号设置。
- **验收**：访客一次操作可进入 PAGE-004；受限入口清楚说明登录原因；不展示虚构个人统计或生成内容。

### PAGE-002 注册

- **角色**：访客。
- **目标**：创建学习者账号，并在需要时承接访客的待保存结果。
- **数据**：创建 DATA-003、DATA-004、DATA-018；可消费 DATA-017。
- **能力**：CAP-002、CAP-011、CAP-021。
- **主要区域**：用户名、密码、确认密码；规则提示；提交；转到登录；存在待保存结果时显示“注册后保存当前内容”的明确上下文。
- **关键状态**：默认、字段错误、用户名占用、提交中、成功；承接仍有效/已丢失。
- **离开路径**：认证后返回 PAGE-004 完成承接，或进入 PAGE-001。
- **验收**：不出现邮箱、手机和年龄字段；失效的待保存结果不会被误报为已保存。

### PAGE-003 登录

- **角色**：访客、已退出用户。
- **目标**：建立会话并按角色或原意图继续。
- **数据**：读取 DATA-003、DATA-018，创建 DATA-004；可消费 DATA-017。
- **能力**：CAP-003、CAP-011、CAP-021。
- **主要区域**：用户名、密码、登录；转到注册；存在待保存结果或受限页面意图时说明登录后的去向。
- **关键状态**：默认、凭据错误、提交中、成功、待保存结果已丢失。
- **离开路径**：学习者回原目标、PAGE-004 或 PAGE-001；管理员进入 PAGE-101。
- **验收**：不提供“忘记密码”自助流程；不能在页面选择角色或组别；错误不暴露账号是否存在。

### PAGE-004 造文

- **角色**：访客、学习者。
- **目标**：完成从选词、配置、流式生成到保存或放弃的完整资源生产链。
- **数据**：读取 DATA-001、DATA-002、DATA-006、DATA-008、DATA-009、DATA-018；创建 DATA-010、DATA-011，登录保存时创建 DATA-012/013，访客保存时创建 DATA-017。
- **能力**：CAP-006、CAP-007、CAP-008、CAP-009、CAP-010、CAP-011、CAP-021。
- **主要区域**：
  1. 词条搜索、候选、已选词条和组上限；
  2. 模型、释义目标语言、场景、短文长度四个必选控件；
  3. 剩余滚动额度和不可生成原因；
  4. 生成/取消操作与流式输出；
  5. 完成后的英文短文、一组短文级标签，以及逐个输入原词的独立释义和提示短语；
  6. 登录学习者的保存/放弃，或访客的登录/注册后保存。
- **关键状态**：空选择、配置未完成、可生成、预检失败、排队前提交、流式生成、用户取消、系统/网络失败、结果校验失败、完整有效、保存中、已保存、已放弃、访客认证承接。
- **交互约束**：每次必须显式选择四项配置，不自动恢复上次值；流式中不可保存且同一主体不能再发起；刷新/离开会明确提示当前结果将丢失但不提供恢复；切换界面语言不重置已选配置或流式状态，也不改变释义目标语言。
- **离开路径**：重新造文、PAGE-005、PAGE-006、PAGE-002、PAGE-003、PAGE-001。
- **验收**：所有非成功状态都给出下一步；只有完整有效结果出现保存；访客承接不再次调用模型；页面不提供自由 Prompt 或额外输入。

### PAGE-005 学习记录

- **角色**：学习者。
- **目标**：查看全量统计并找到、管理所有当前保存批次。
- **数据**：读取 DATA-002、DATA-012 至 DATA-016、DATA-018；可更新或删除 DATA-012 及关联数据，可恢复或创建单批次 DATA-014。
- **能力**：CAP-012、CAP-013、CAP-015、CAP-016、CAP-020、CAP-021、CAP-022。
- **主要区域**：六项统计摘要；词条搜索；从旧到新的批次列表及短文级标签；“参与复习” checkbox；打开详情、直接复习本批、删除操作。
- **关键状态**：首次空状态、正常列表、搜索无结果、参与状态切换、单批次新建/恢复/不可用、删除确认、删除成功/失败。
- **离开路径**：PAGE-004、PAGE-006、PAGE-007、PAGE-008、PAGE-009。
- **验收**：默认顺序始终从旧到新；搜索仅按目标词条；暂不参与日期范围复习的批次仍可见且可直接复习；同批未完成单批次会话优先恢复；删除必须明确确认且不会暗示可恢复。

### PAGE-006 批次详情

- **角色**：学习者。
- **目标**：完整回看一个保存批次并管理其复习状态或删除。
- **数据**：读取 DATA-012、DATA-013、必要 DATA-015、DATA-018；可更新/删除 DATA-012。
- **能力**：CAP-014、CAP-015、CAP-016、CAP-021。
- **主要区域**：保存时间与“参与复习”状态；模型用户可见名称、语言、场景、长度；短文级标签与完整短文；已保存的原词释义和提示短语；参与复习 checkbox、永久删除。
- **关键状态**：正常、无权访问、已删除/不存在、操作确认。
- **离开路径**：返回 PAGE-005、前往 PAGE-007、PAGE-004。
- **验收**：内容只读且配置为生成时快照；模型停用不影响显示；其他账号不能通过地址访问。

### PAGE-007 复习范围

- **角色**：学习者。
- **目标**：选择复习日期范围、了解命中内容，并开始或恢复日期范围会话。
- **数据**：读取 DATA-012、DATA-014、DATA-015、DATA-018；创建 DATA-014。
- **能力**：CAP-017、CAP-020、CAP-021。
- **主要区域**：默认最近 7 天的开始/结束本地日期；包含边界提示；参与日期范围复习的批次命中数量；开始复习；如有未完成日期范围会话则提供恢复及进度摘要。
- **关键状态**：有可复习批次、无命中、无学习记录、日期错误、有可恢复会话。
- **离开路径**：PAGE-008、PAGE-005、PAGE-004。
- **验收**：只统计勾选“参与复习”的批次；创建会话时固定两层随机顺序；空范围不进入空白复习页；PAGE-005 创建的单批次会话不在此处覆盖或替代日期范围恢复入口。

### PAGE-008 复习过程

- **角色**：学习者。
- **目标**：在日期范围或单批次会话中，按固定随机顺序完成每个批次的词条拼写与短文挖空，并获得批次级和会话级结果。
- **数据**：读取 DATA-012、DATA-013、DATA-014、DATA-018；创建 DATA-015，更新 DATA-014、DATA-016。
- **能力**：CAP-018、CAP-019、CAP-020、CAP-021。
- **主要区域**：与会话模式相符的会话/批次进度；阶段标识；阶段一已保存的原词释义、单次输入、默认关闭的提示开关及全部目标位置挖空的提示短语；阶段二整篇挖空短文、每个空的匿名同词组提示和各答案输入；检查、重试、跳过、下一批次；结束总结。
- **关键状态**：日期范围会话、单批次会话；阶段一作答、错误、正确、跳过；阶段二作答、错误、正确、跳过；批次成功/未成功；会话完成；中断后重启当前批次；批次已删除。
- **交互约束**：任何时候不显示正确答案；提示短语含多个同目标位置时全部遮蔽但仍只提供一次原始词条输入；阶段二同一原始词条的全部词形共享匿名组，不同原型不同组，每个空仍单独输入。正常视觉界面不显示数字组号，优先随机配色且当前阶段内不跳变；设计必须以不显示拼写、非显式数字的方式覆盖颜色不足、色觉差异和辅助技术。错误保留重试机会；跳过不阻止前进但使该批次不能成功；提示开关只影响当前交互且进入页面默认关闭；切换界面语言不重排题目、改变分组或清除当前输入与进度。
- **离开路径**：日期范围恢复入口 PAGE-007、单批次入口/学习记录 PAGE-005、继续造文 PAGE-004。
- **验收**：已完成批次结果即时保存；刷新当前批次会从阶段一开始且不重复已完成批次；两种会话不互相覆盖；成功判定和统计一致。单次、多次及不同词形 occurrence 均按正文首次出现顺序形成稳定同词关系，每个空都有可感知分组但不显示拼写或可见数字组号。

### PAGE-009 账号设置

- **角色**：学习者。
- **目标**：管理自身密码、当前会话和账号生命周期。
- **数据**：读写/删除 DATA-003、DATA-004、DATA-018，并在注销时删除所属 DATA-009、DATA-012 至 DATA-018。
- **能力**：CAP-003、CAP-004、CAP-005、CAP-021。
- **主要区域**：只读用户名和当前组别；修改密码；退出当前会话；注销账号危险区域。
- **关键状态**：改密默认/错误/成功；注销密码校验、明确第二次确认、删除中、完成。
- **离开路径**：PAGE-001、PAGE-003；注销成功后仅能重新注册。
- **验收**：用户名不可编辑；注销文案明确立即、永久、无导出/恢复；改密与注销的会话结果符合数据契约。

## 3. 管理员页面

管理员区使用统一后台壳层，只提供三个一级入口和当前会话退出，不增加独立仪表盘。任何管理员写操作都需要服务端重新验证管理员角色。

### PAGE-101 OpenRouter 与模型

- **角色**：管理员。
- **目标**：确保模型供应配置可用并维护可分配模型。
- **数据**：读写 DATA-007、DATA-008，读取 DATA-006 的引用关系、DATA-004 当前会话和 DATA-018。
- **能力**：CAP-003、CAP-021、CAP-101、CAP-102。
- **主要区域**：全局密钥脱敏状态与替换表单；模型列表；模型名称、说明、原始 ID、启用状态的新增/编辑；组引用提示；退出。
- **关键状态**：未配置密钥、已配置、保存失败；无模型、启用/停用、模型被组引用。
- **离开路径**：PAGE-102、PAGE-103、PAGE-003。
- **验收**：密钥从不回显；原始模型 ID 不出现在学习者页面/API；停用不会删除历史内容。

### PAGE-102 组别配置

- **角色**：管理员。
- **目标**：配置四个固定组的生成选项与额度。
- **数据**：读写 DATA-006，读取 DATA-008、DATA-018。
- **能力**：CAP-021、CAP-103。
- **主要区域**：四个固定组切换；每组可用模型多选、长度多选、单次最大词条正整数、滚动 24 小时次数或不限；不可生成配置警告。
- **关键状态**：有效配置、无模型、无长度、零额度、非法输入、未保存变更、保存成功。
- **离开路径**：PAGE-101、PAGE-103。
- **验收**：页面没有增删改名组操作；允许有意保存不可生成配置但清楚提示后果；变更不改写历史批次。

### PAGE-103 用户管理

- **角色**：管理员。
- **目标**：按用户名定位账号，处理换组、密码重置并只读查看学习库。
- **数据**：读取/有限更新 DATA-003、DATA-004、DATA-006、DATA-009，读取自己的 DATA-018；只读 DATA-012、DATA-013、必要 DATA-015。
- **能力**：CAP-003、CAP-021、CAP-104、CAP-105、CAP-106、CAP-107。
- **主要区域**：用户名搜索与结果；用户角色/组别；换组确认及额度重置说明；直接设置新密码及会话失效说明；含短文级标签的只读批次列表和详情；退出。
- **关键状态**：无结果、用户详情、换组确认/成功、重置密码确认/成功、学习库空状态、只读详情。
- **离开路径**：PAGE-101、PAGE-102、PAGE-003。
- **验收**：没有冒充、删除账号、修改/删除/暂停用户内容或授予管理员入口；直接调用对应越权操作也被拒绝。

## 5. 页面级验收

1. 所有 CAP-001 至 CAP-022、CAP-101 至 CAP-107 至少映射到一个页面。
2. 所有页面只引用 `data-assets.md` 中定义的数据 ID，并且读写权限不超过 `abilities.md`。
3. 访客、学习者和管理员的直接地址访问、导航和登录后返回路径均符合角色边界。
4. 空、加载、错误、无权、删除和流中断状态都能给出明确结果或下一步，不依赖仅颜色表达。
5. UI/UX 阶段可以调整布局和视觉层级，但不得合并掉本文件规定的关键状态、确认或角色隔离。
6. 全部 12 个页面均可在 `zh-CN` 与 `en-US` 下完成主任务；语言切换保留路由、配置、生成或复习状态，并且不改写 AI 生成内容语言。
7. 全部页面、断点、浏览器标题和可访问名称均按当前界面语言只呈现一个品牌名称；`zh-CN` 为“词涟”，`en-US` 为“WordWeave”，不出现双语品牌并列。
8. PAGE-005 对参与和暂不参与日期范围复习的批次都提供直接复习；单批次会话与 PAGE-007 日期范围会话分别恢复且互不覆盖。
9. PAGE-008 的阶段二在全部支持视口与输入/错误状态下保持匿名同词分组可辨识；随机颜色在当前阶段内稳定，颜色不足与无障碍场景有非拼写、非显式数字的补偿方式，且输入框、分组提示和正文不重叠。
10. PAGE-004、PAGE-006、PAGE-008 阶段一与 PAGE-103 只读查看使用同一份原词释义，遵循 [C40-04](../ai-behavior.md#cr040-acceptance)；不以界面截尾掩盖生成内容的问题，不因本次修订改变布局或已批准的交互方案。
