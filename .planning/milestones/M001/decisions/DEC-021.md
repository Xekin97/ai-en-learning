# Tag 归属于整篇短文

## 发现的矛盾

`DEC-009` 已确认“每篇短文生成 1 至 3 个目标语言标签”，但产品规划后续把 `tags` 放进了每个目标词条资源，导致原型也把标签展示在单词卡片内。

## 用户决定

`CONFIRMED`：Tag 描述整篇生成短文，不描述单个目标词条。

1. 每个生成批次只有一组 1–3 个短文 Tag，使用当次选择的释义目标语言。
2. 每个目标词条仍只有情境释义、提示短语、实际词形和挖空位置，不拥有独立 Tag。
3. 短文 Tag 只展示；M001 不增加 Tag 搜索、筛选或编辑能力。
4. 生成结果、学习记录和批次详情都把 Tag 放在短文/批次层级，不放进词条卡片。

## 影响范围

- 产品规划的 overview、data-assets、abilities、pages 和 ai-behavior 需要统一纠正。
- AI 输出结构应把 `tags` 从词条对象移到批次/短文对象。
- 数据设计应把 Tag 归入批次而不是批次目标资源。
- UI/UX 原型和设计说明立即按本决策修订，由 `CR-002` 追踪上游同步。
