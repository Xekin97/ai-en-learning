# 产品名称与页面默认行为

## 决策问题

设计阶段开始前需要锁定 M001 产品名称，并明确造文配置是否自动沿用，以及复习短语提示的默认状态。

## 用户决定

`CONFIRMED`：

1. 中文名“词涟”和英文名“WordWeave”从暂定名称转为 M001 正式产品名。
2. 用户每次生成都必须明确选择模型、翻译目标语言、场景和短文长度。
3. M001 不保存或自动恢复用户上一次生成配置，避免隐式使用用户未重新确认的模型或配置。
4. 复习页的短语提示开关默认关闭；用户需要提示时主动开启。
5. 提示开关只影响当前复习交互，不改变批次保存内容或正确答案规则。

## 影响范围

- `overview.md` 与后续设计统一使用“词涟 / WordWeave”。
- 造文页不能未经用户选择直接发起生成，也不显示来自历史偏好的隐式默认值。
- 复习页进入时短语提示关闭，UI/UX 必须让用户能够发现并理解开关作用。
