## 1. 设计 Token

唯一主题源为 [`theme.css`](./theme.css)。后续前端实现可以转换为框架 Token，但不得改变语义角色。

### 1.1 色彩角色

| Token | 用途 | 约束 |
| --- | --- | --- |
| `--color-canvas` / `--color-canvas-soft` | 暖纸张背景 | 不作为输入边框或正文文字 |
| `--color-surface` / `--color-surface-raised` | 卡片、阅读稿、输入层 | 阅读长文使用纯净表层，减少纹理干扰 |
| `--color-ink` / `--color-ink-soft` / `--color-ink-faint` | 主文字、辅助文字、元信息 | faint=#596c6b，用于弱文本与既有 empty-state 继承（含访客 h1）；不承载错误或主操作，不豁免小字号对比度要求 |
| `--color-brand` / `--color-brand-strong` / `--color-brand-soft` | 主操作、当前状态、选中态 | 不把品牌绿同时用作危险成功和普通装饰 |
| `--color-accent` | 编织线条与少量品牌强调 | 不作为主按钮或大面积背景 |
| `--color-success/info/warning/danger` | 确定性状态反馈 | 状态必须同时有文字/图标，不能只靠颜色 |
| `--color-focus` | 键盘焦点 | 所有可交互元素保持清晰焦点环 |

阶段二匿名同词组另使用六个 AA 边框色作为随机视觉投影，并同时叠加实线、虚线、点线或双线纹理。颜色不承担唯一语义；同组焦点联动与仅辅助技术可读的匿名组名始终存在。组色不写入业务数据，也不复用成功、警告或错误文案语义。

色彩组合按 WCAG 2.2 AA 目标设计：普通正文与背景至少 4.5:1，大字号和非文字控件至少 3:1。技术实现阶段需要用最终渲染字体与浏览器再次自动检查。

### 1.2 字体角色

- `--font-ui`：系统无衬线字体栈，用于中文、日文、导航、控件、表格和状态。
- `--font-reading`：系统阅读型衬线字体栈，用于英文短文、英文词条、品牌大标题和复习主提示。
- `--font-mono`：仅管理员原始模型 ID 和脱敏技术值。
- 不依赖远程字体，保证原型离线打开仍可读；实现若引入 Web Font，必须有相同角色的系统回退并避免阻塞首屏文字。
- 文案容器不使用依赖中文长度的固定宽度；英文、未来其他语言和 200% 缩放时允许自然增长、换行或省略。

### 1.3 间距、圆角与层级

- 间距使用 4px 基准的 `--space-*` 序列，不以页面单独硬编码创造新节奏。
- 控件最低高度 `44px`，移动端主要触控目标最小 `44 × 44px`。
- 普通卡片使用 `--radius-lg`，认证/复习主卡使用 `--radius-xl`，Chip 和按钮使用 Pill；危险对话框不通过夸张造型制造恐慌。
- 阴影只区分页面层、卡片层和模态层；信息层级优先使用留白、边框和字体，不堆叠浮层。

## 2. 响应式布局

### 2.1 大桌面：≥ 1081px

- 内容容器最大宽度 1216px，左右至少 24px 安全边距。
- PAGE-004 为 304–344px 紧凑配置栏 + 自适应输出栏；配置栏在视口内 Sticky，独立滚动但主按钮保持可达。
- 词汇候选浮层与搜索框同宽、覆盖后续配置而不改变其位置；最大高度为 12rem 或视口高度的 45%，取较小值，超出后局部滚动。
- 配置栏中模型使用紧凑单列行；释义语言使用三列，场景使用两列，篇幅使用四列，避免重复说明占用纵向空间。
- 英文短文最大阅读宽度约 68ch，不因大屏无限拉长。
- PAGE-005 六项统计同排；PAGE-006 主内容 + 288px 侧栏。
- 管理员使用 248px 固定侧栏和自适应内容区；账户工具区贴近侧栏底部，但使用正常 Flex 流而非绝对定位堆叠。
- PAGE-103 搜索结果为单栏行列表，每行按“身份 → 当前方案 → 状态 → 查看”排列；详情使用账号信息与只读学习库双栏。加载骨架占用与结果近似的稳定高度。

### 2.2 中等桌面/平板：721–1080px

- 六项统计改为 3 × 2。
- PAGE-004 在 901px 以上仍双栏；≤900px 改为单栏，配置栏取消 Sticky，输出紧随其后。
- PAGE-006、PAGE-007、PAGE-009 改为单栏，次要卡片排在主任务之后。
- 管理员侧栏 ≤900px 转为两行顶部栏：第一行是随界面语言显示的单一品牌、语言和退出，第二行是等宽三个导航入口。
- PAGE-103 在 721–900px 保持结果行语义顺序，但详情改为单栏；用户名区域允许扩展，方案、状态和查看操作不得挤压用户名到不可读宽度。

### 2.3 手机：320–720px

- 页面左右安全边距 16px，主按钮在结果操作区占满宽度。
- 主导航与账号入口收进可访问的导航对话框；页头保留当前界面语言对应的单一品牌名称、紧凑语言入口和导航按钮。
- 访客的登录/注册与学习者的账号设置都可从导航对话框取得，避免 320px 下挤压、截断品牌或压缩导航图标。
- PAGE-004 顺序为：词条 → 四项配置 → 额度与主按钮 → 流式/结果；仍是同一 PAGE，不改成新的向导业务流程。
- 词汇候选在手机上仍锚定搜索框并覆盖后续内容，不扩张卡片或页面高度；浮层不得越过配置卡左右安全边界。
- 模型在 320–720px 始终单列，不能被通用双列选择器覆盖；名称固定可见，说明在剩余宽度内省略，不推动卡片越出配置栏。
- 释义语言、场景和篇幅保持两列，避免每个短标签独占一行；生成结果资源卡单列。
- PAGE-005 统计在较宽手机上可两列，≤560px 单列；批次动作换行，“复习本篇 / 继续本篇”保持清晰主操作，“参与复习” checkbox 保持完整标签并与危险操作分离。
- PAGE-008 会话来源、保存日期/日期范围和返回入口在窄屏纵向排列；主提示和答案左对齐，提示短语中的多个空随自然语句换行且不挤出卡片。阶段二每个空由 `inline-flex` 行内容器承载，输入高 `2.25em`、行内容器最小高 `2.5em`、正文行高至少 `3.1`；输入统一宽度且不超过 `42vw`，允许在空前自然换行，标点保留在空后正文流中。底部操作纵向排列，主操作视觉顺序在上、DOM 顺序保持合理。
- PAGE-103 搜索表单纵向排列并让主按钮占满宽度；结果身份区独占首行，方案与状态置于次行，“查看”占满末行。详情返回按钮独占一行，长查询摘要截断但完整查询仍保留在搜索框中；不得出现页面级横向滚动。
- 表格容器可横向滚动，不能通过缩小到不可读字号塞入屏幕。

### 2.4 内容极端情况

- 用户名 32 字符、18 字符词条和多词词条允许换行或省略，但完整值在可聚焦元素中可取得。
- 短文无最大词数，阅读画布随内容增长，不在内部创建难以操作的固定高度滚动区。
- 管理员可配置很大的词条上限；界面只显示实际选择数量和组限制，不尝试一次铺满全部占位。
- 中文、英文、日文释义均使用自然换行；标签 1–3 个并可换行，不固定宽度。
- 配置栏、字段、选择网格及选择卡都必须设置可收缩边界；切换较长界面语言后不得产生页面级或卡片级非预期横向溢出。
- 模型名称允许在自身区域自然换行，说明限制在剩余宽度内省略；任何界面语言都不能通过 `white-space: nowrap` 把选择卡撑出配置栏。
- 短文 Tag 在阅读区头部成组换行；词条卡不为 Tag 预留空间。
- 账号语言同步失败 Notice 在窄屏改为纵向布局，重试按钮占满可用宽度，不遮挡当前页面或悬浮原型面板。
- 语言名称使用其本地称呼或短标签，选择器宽度不依赖单一语言；未来语言超过当前空间时使用弹出菜单而不是继续压缩品牌。
- 阶段二支持任意目标词条数量：优先使用不重复颜色，再组合四种边框/底纹；视觉组合被复用时，聚焦任一空必须只强化其真实同组空。组数增加不得改变固定输入宽度或通过空宽暗示答案长度。
- PAGE-103 的 32 字符用户名在列表和详情自然换行，不扩大网格最小宽度；加载、无结果和错误状态与正常结果使用相同容器宽度。继续加载只追加结果，不把搜索框或已显示行推离可恢复位置。

## 3. 键盘与焦点

- 页面开头提供“跳到主要内容”链接。
- 路由切换后焦点移动到 `<main>`；错误提交后移动到第一个错误字段；打开对话框后浏览器原生 Dialog 管理初始焦点和焦点约束。
- 对话框可用 `Escape` 关闭，永久危险确认若未来需要阻止 Escape，必须另行验证且不得形成焦点陷阱。
- 自定义选择卡保留原生 Radio/Checkbox，键盘方向键、Space 与屏幕阅读器语义由原生控件承担。
- Tab、组别 Tab 和导航当前项分别使用 `aria-selected`、`aria-current`，不只改变视觉颜色。
- 界面语言选择使用原生 Select；切换后更新 `<html lang>`，保留焦点上下文与当前任务状态。账号偏好保存失败时焦点仍回到语言选择，随后可进入就地“重试”按钮。
- Chip 删除按钮拥有包含词条名称的可访问标签。
- 复习内联挖空字段按短文阅读顺序进入 Tab 序列；错误后焦点返回当前空，不跳到下一题。
- 阶段二任一空获得焦点时，同组所有空同步强化，其余组降低饱和度；焦点本身仍使用独立高对比焦点环。错误提交后焦点回到正文顺序中的第一个待修改空，分组投影不重新随机。
- PAGE-103 搜索提交后焦点进入结果标题；结果的“查看”按钮按用户名结果顺序进入 Tab。详情返回后焦点恢复到刚才的“查看”按钮；继续加载后焦点保留在加载按钮或移到首个新增结果，由实现选择一种并全程一致。

## 4. 屏幕阅读器与状态播报

- 页面只有一个主要 `<h1>`；卡片标题按层级使用 `<h2>/<h3>`。
- 流式内容区域可使用节流后的 `aria-live="polite"`，避免每个 Token 都播报；状态文字“正在生成临时内容”必须立即可读。
- Toast 使用 `aria-live="polite"`，认证失败、删除失败和复习答案错误使用就地 `role="alert"`。
- 可用次数、完成、错误和是否参与复习都包含自然语言文字；圆点、颜色和动画仅作辅助。
- PAGE-005 / PAGE-006 的“参与复习”使用原生 checkbox，可由键盘切换，并通过 `checked` 状态与完整标签向辅助技术表达，不用颜色或按钮文案推断状态。
- PAGE-005 的每个批次直接复习操作都包含完整可见文案；checkbox 状态变化后焦点返回同一 checkbox，且不会移除相邻直接复习操作。
- 图标默认 `aria-hidden="true"`；纯图标按钮必须有准确 `aria-label`。
- PAGE-008 的会话来源以文字标签表达；进度条使用可读的批次/阶段文字，并提供 `aria-label` 或标准 Progress 语义，不只显示一条色带。
- 阶段一短语挖空的隐藏答案文字不能留在可访问树中；视觉占位不包含真实答案。每个重复位置只提供通用“挖空”读屏文本，所有位置共同关联同一个原始词条输入，不生成多个可聚焦答案框。
- 阶段二未揭晓答案不得通过 `value`、`title`、隐藏 DOM、自动完成或可复制样式泄露。每个输入的名称仅包含“短文空白”和仅辅助技术可读的匿名组名；同一词条复用同一匿名名称，不同词条不可复用，名称不含拼写、词形、长度或选词序号。
- PAGE-103 搜索容器使用 `role="search"`，加载容器使用 `aria-busy`，结果数量使用 `aria-live="polite"`；结果以语义列表呈现，每个“查看”按钮的名称包含用户名。无结果是礼貌状态，服务错误为 `role="alert"`，不能只显示空白列表。

## 5. 表单、错误和输入辅助

- 每个输入都有永久 Label；Placeholder 只补充示例，不能替代 Label。
- 用户名、密码和日期规则在提交前可见；错误说明具体如何修正，但登录错误不确认账号存在。
- 生成按钮禁用时，空选择本身应足以说明下一步；若系统配置不可用，则只提示“暂时无法开始”，不暴露组策略或调用阶段。
- 第一阶段输入关闭拼写自动纠正与可能泄露答案的建议；浏览器自动完成策略由前端技术阶段根据可访问性和安全共同确定。
- 答案比较规则由系统正确执行；题面使用自然任务文案，不把大小写、词形和内部判定规则堆到学习界面，同时不显示任何候选答案。
- 删除与注销确认不能预勾选二次确认 Checkbox。

## 6. 动效、阅读与认知负担

- 遵守 `prefers-reduced-motion`，关闭光标闪烁之外的非必要动画；即使关闭动画，流式状态仍以文字和增量内容成立。
- 不用模拟固定生成百分比，因为产品没有响应时间或进度 SLA。
- 长阅读正文行高约 1.85、最大 68ch；中文控制文本保持约 1.55 行高。
- PAGE-008 普通阅读仍使用约 1.85 行高；只有包含行内作答框的阶段二正文提高至至少 3.1，以输入上下各保留不小于约 `0.3em` 的视觉间隔。320、390、720 与桌面断点均不得通过负 margin、绝对定位或固定单行高度压缩空位。
- 复习页面移除全局次要导航干扰，但保留可安全退出路径和中断规则说明。
- 错误色不用于学习者正常“尚未完成”，避免把学习过程持续呈现为失败。

## 7. 可访问性验收清单

1. 仅用键盘可以进入所有 12 个 PAGE 的主任务、打开/关闭对话框并完成原型关键路径。
2. 320px、720px、900px、1080px 和宽桌面下无非预期水平滚动；管理员表格是明确允许的局部滚动。
3. 200% 浏览器缩放下内容不重叠，主操作和错误信息仍可取得。
4. 深浅文字、边框、焦点、状态组合通过 WCAG 2.2 AA 对比度检查。
5. VoiceOver 或 NVDA 能读出页面标题、当前导航、字段 Label、生成状态、两层复习进度和错误反馈。
6. 关闭动画后生成、取消、校验、保存与 Toast 状态仍完整可理解。
7. 错误与跳过路径的 DOM、可访问名称和自动完成均不泄露复习答案。
8. 危险操作的焦点顺序、默认按钮和后果文案不会诱发误删除。
9. 中文与英文逐页检查无混杂文案；中文界面品牌只显示“词涟”，英文界面只显示“WordWeave”，同一品牌接触点不得并列两者。
10. 切换界面语言不改变释义语言、已选词语、生成状态或复习进度。
11. 在 561–720px 范围分别切换中文和英文，模型选项保持单列且完整位于配置容器内。
12. 320px 下当前语言的单一品牌名称、语言入口和导航按钮均可见且互不遮挡；访客登录/注册可从导航对话框取得。
