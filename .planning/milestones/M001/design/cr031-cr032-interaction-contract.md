# 访客认证引导与只读短文弹窗：前端交互交付

本文件和同步原型是本轮**待批准**设计，批准后取代旧稿中冲突的引导/弹窗规则；其余设计保持不变。它不代表前端已实现或独立测试通过。

## 1. 访客进入 Review / Library

### 唯一目标与文案

入口只决定目标，不决定文案版本。Header、首页按钮、移动导航、直接地址和原型控制器都按稳定页面标识使用下表；禁止按选项序号、点击来源或 `PAGE_DEFS.title` 拼接消息，也禁止局部翻译整句。

| 目标 | 设计页面 / 正式路由 | 中文标题 | 英文标题 |
| --- | --- | --- | --- |
| `review` | PAGE-007 / `/review` | 登录后打开“复习” | Sign in to open Review |
| `library` | PAGE-005 / `/library` | 登录后打开“学习记录” | Sign in to open Library |
| `story` | PAGE-006 / `/library/:batchId` | 登录后查看这篇短文 | Sign in to view this story |
| `account` | PAGE-009 / `/account` | 登录后管理账号 | Sign in to manage your account |

Review 和 Library 共用其余内容及视觉：

| 元素 | 中文 | English |
| --- | --- | --- |
| 顶部小标题 | 需要登录 | Sign in to continue（由 eyebrow 样式大写） |
| 说明 | 登录后即可继续复习并保留学习记录。 | Keep your library and continue reviewing from any session. |
| 主按钮 | 登录并继续 | Sign in and continue |
| 次按钮 | 创建账号 | Create account |

- 保持当前受限页地址和对应导航高亮，呈现完整公共 Header 与整页引导卡；不自动跳到登录页，不加载/闪现日期表单、统计或私有批次。
- 页面布局沿用 `.container.page-section > .empty-state.card`、钥匙图标、居中标题和双操作；原型面板为脱离文档流的审阅工具，不进入产品组件。
- PAGE-006 显示 Story 引导，不显示 Library 或 Review 的内部页面名；受限短文在认证前不能展示用户名、词语、保存日期等私有元数据。
- PAGE-008 的 `/review/:sessionId` 使用 `review` 文案。认证后重新验证有效会话；有效则按已批准恢复规则继续，不存在/无权则走既有安全状态。只有没有有效会话目标时才返回 PAGE-007，不能仅因登录成功新建会话。
- 原型面板 PAGE-007 明确标为 `PAGE-007 · Review` / `PAGE-007 · 复习`；PAGE-006 为 `Story` / `短文详情`。状态下拉只改变同一页面的演示状态，访客下所有 PAGE-007 状态都保持同一个 Review 引导。

### 登录 / 注册往返

1. 点击引导主/次按钮分别进入 `/login?redirect=<原目标>`、`/register?redirect=<原目标>`，目标仅允许站内受支持地址；目标名称从固定映射取得，不把 URL 显示为标题。
2. 登录与注册互切必须保留同一 redirect 和合法批次/会话标识；字段错误、通用认证错误和切换界面语言不清除意图。原型也演示受限目标在认证页刷新后仍保留。
3. 表单上方使用同一条轻提示表达去向：Review 为“完成后返回复习。” / “Continue to Review when you’re done.”；Library 为“完成后返回学习记录。” / “Continue to Library when you’re done.”。没有原目标时不出现此提示。
4. 认证成功先应用账号语言偏好，再按角色返回：学习者到原目标；管理员进入既有管理员区，不显示学习者资源。注册直接得到学习者会话后同样返回。
5. 认证不自动开始复习，不自动保存内容。DATA-017 访客待保存短文沿用既有专用承接流程，优先于普通导航意图；该临时结果仍不能通过刷新恢复。
6. 返回引导页后目标不变；改去首页、造文或另一个主任务则清除旧意图，不能在下一次普通登录时意外跳回旧 Review。无效/外部 redirect 按既有安全回退处理。
7. 正式浏览器后退应回到原引导/任务上下文。原型仅以 `replaceState` 同步可分享的当前审阅 URL，不模拟完整浏览器路由历史；前端应单独测试浏览器后退、失效会话与真实账号角色分流。

完整消息集中于 `prototype/i18n.js` 的 `messages`，导航目标集中于 `prototype/app.js` 的 `AUTH_TARGETS`。前端应转为项目既有本地化键与视图状态映射，不能拷贝原型的字符串替换机制。

## 2. 管理员只读短文弹窗

### 布局与内容

保留居中模态阅读方式，不改为新页面。使用暖纸张底色与现有阅读字体，扩宽阅读空间，通过区域留白形成层级，不堆叠提示框。

| 区域 | 内容 | 间距 / 行为 |
| --- | --- | --- |
| 固定标题 | 用户短文 / Learner story；只读 / Read only；当前用户名、保存日期；右上角关闭 | Desktop 左右 32px、上下 20px；手机左右 20px、上下 16px；关闭 44×44px |
| 配置快照 | 模型、释义语言、场景、篇幅 | Desktop 四列，≤720px 两列；不展示内部模型 ID |
| 阅读区 | 短文标题、短文级标签、完整英文正文 | 分区间隔 32px，手机 24px；标签到正文 24px；正文 18px / 1.9，最大 68ch；段间 24px |
| 词条资源 | 原始词条、情境释义、英文提示短语 | Desktop 词条 / 资源两列；手机单列；每条上下 20px，释义与短语间 8px |
| 固定底部 | 关闭 / Close | 次级按钮；手机占满宽度；不出现复习、参与开关、编辑、删除或保存 |

- 桌面宽 `min(896px, 100vw - 48px)`，高不超过 `100dvh - 48px`；手机（≤720px）宽不超过 `100vw - 32px`，高不超过 `100dvh - 32px`。短内容自然收缩，长内容只滚动 `.reader-body`，标题和底部不跟随滚走。禁止在正文、词条列表内再套第二个滚动区。
- 外层页面在弹窗打开期间禁止滚动，背景搜索/详情不卸载。关闭后保留当前用户、搜索值、结果集合、列表位置、底层滚动位置和原“查看”按钮焦点。
- 打开时向当前 `userId + batchId` 请求，不能固定取首条批次。新请求不得展示前一个用户或批次缓存内容；关闭后迟到结果不得重新打开弹窗。错误重试也必须保留同一目标。
- 标题行的只读标识始终可见，替代旧稿紧挨标签的冗余 Notice。保存日期及用户名只取已授权、已获得的上下文；直接深链接尚无上下文时不凭空填充。
- 正文完整显示且允许选择复制，不截断、不折叠、不以单词数上限隐藏长文。标签仅在短文层出现一次，可以换行；资源不增加独立标签。
- 原型的两条批次具有不同正文、标签、保存日期与资源；长/特长状态是独立的压力演示，非真实 AI 输出质量证据。词条释义和标签按生成时的目标语言保留，界面语言切换不翻译它们。

### 状态与键盘

| 状态 | 内容 | 操作 |
| --- | --- | --- |
| 加载 | 正在加载短文… / Loading story…；静态骨架，`role=status`、`aria-busy=true` | 顶部/底部关闭；不可显示旧正文 |
| 成功 | 配置、标签、正文、词条完整展示 | 只读滚动、关闭 |
| 网络/服务失败 | 暂时无法加载短文 / Couldn’t load this story；请稍后重试。 / Please try again.；`role=alert` | 重试 / Try again，关闭 |
| 已删除/无权 | 找不到这篇短文 / This story is unavailable；它可能已被删除，或你无法查看。 / It may have been deleted or is no longer available to you. | 关闭；不泄露归属、不提供无意义重试 |

原生模态 Dialog 或等价实现：打开时聚焦标题，Tab/Shift+Tab 限制在弹窗；内容区可聚焦并用键盘滚动；Escape、关闭图标、底部关闭和遮罩关闭结果相同。点击内容留白不能误关闭。标题、只读状态、关闭名称完整可读，不隐藏焦点环。

原型状态：PAGE-103 的 `batch-short / batch-long / batch-xlong / batch-loading / batch-error / batch-unavailable`。下拉控制器只用于预览，正式产品不提供这些状态开关。

## 3. 注销区域与其余返工基线

- PAGE-009 副标题维持“这项操作无法撤销。” / “This can’t be undone.”，说明正文维持“你的短文、复习记录和账号信息都会被删除。” / “Your stories, review history, and account will be deleted.”。
- 副标题使用现有 `--color-ink-soft: #40585a`，背景为 `--color-danger-soft: #fae9e7`；实测普通文字对比度为 6.47:1。不使用旧浅灰 `#6d7f7e`，也不把这句辅助说明改为生产实现的暗红。
- 删除标题、边框、危险按钮、二次确认流程不变。
- CR-029 其余项沿用旧批准稿：Review 的 From/To 控件均为 44px，同一行 `.field + .field` 不加额外上边距；首页学习者英文次按钮为 `Review`。
- CR-030 其余项沿用已批准用户详情设计：搜索可继续使用；返回按钮 `← 返回搜索结果` / `← Back to results`；创建日期 ISO `YYYY-MM-DD`，英文前缀 `Joined `；Library 副标题 `仅供查看` / `View only`；批次操作 `只读查看` / `View`。弹窗采用本轮新稿，不再跳独立批次页。

## 4. 下游边界与验收
