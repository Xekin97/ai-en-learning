## 2. 待确认交互方向

| 方向 | 用户操作 | 收益 | 代价 |
| --- | --- | --- | --- |
| A：保留日期选择器（推荐） | 无命中后直接改原来的日期 | 范围与结果同时可见；不增加步骤；焦点与草稿容易保持 | 空态仍占用日期表单的原有空间 |
| B：空态提供“调整日期” | 先点击返回日期表单，再修改日期 | 空态更简短 | 多一次点击；须额外处理恢复草稿、焦点和往返 |

PROPOSED：采用 A。问题发生在“筛选结果为空”，不是“日期选择任务已结束”；保留输入最符合用户连续调整范围的意图。复用既有卡片、控件、字号与响应式布局，不引入弹窗或新页面。

OPEN：请用户确认是否采用 A。收到确认后再更新可运行原型与正式交互说明，并执行设计自检；未经确认不把推荐记录成用户决定。

## 3. 方向 A 的拟定状态边界

以下是待审规则，具体排版和双语文案在原型修订中交付。

- 日期输入在有命中、零命中、无记录、加载、错误和日期无效状态均保留；只在访客未获访问权时不显示。
- 修改日期后只更新结果区，不替换整个表单；保留当前字段、输入值与键盘焦点。不主动跳转或创建复习。
- 有效且最新预览有命中时可开始；预览未完成、失败、无效或零命中时不能使用旧结果开始复习。
- 零命中在日期表单下方显示简洁反馈，并保留学习记录与继续学习入口；不让按钮成为调整日期的必经步骤。
- 清空字段或结束早于开始是日期错误，不伪装成没有短文；开始与结束同一天有效。
- 真正空库与“有历史批次但当前无命中”分别验证，但不能由一次零命中断言用户没有任何学习记录。不要求新增全库计数接口；缺乏可用依据时使用不武断的当前范围文案。
- 未完成日期会话的恢复入口独立于新范围的命中结果；零命中或修改日期不清除、覆盖旧进度。
- 语言切换保留日期草稿与页面状态；品牌继续遵守中文“词涟”、非中文“WordWeave”。
- 保持 From/To 同宽同高 44px、同排时顶部对齐及第二字段无多余 margin；手机按既有断点排列，不以压缩字号或负间距适配。
- 最新状态以礼貌播报反馈；不因预览返回抢焦点；日期错误与字段关联。加载/失败不是零命中，不显示虚假的 0。

## 4. CR-032 颜色基线来源与同步边界

FACT：[CR-010](../changes/CR-010.md) 已记录并关闭全局弱文本对比度修订。当前生产主题 `--color-ink-faint` 为 `#596c6b`，设计主题仍为 `#6d7f7e`。访客引导标题通过 `.empty-state` 继承该值，造成同一差异在多个入口/语言/视口重复出现。

拟同步原型 token 为既有生产值 `#596c6b`，不是另选新色，也不将生产全局回退。影响边界是所有继承该 token 的弱文本/元信息组件，而不只是给访客标题写局部例外；显式覆盖其他 token 的区域不变。已确认的完整引导文案、字号、背景、边距、认证意图均不改。

本地按不透明 sRGB 颜色计算的对比度（2026-09-05；静态计算，不等同浏览器/辅助技术验收）：

| 背景 | 旧 faint #6d7f7e | 既有生产 faint #596c6b |
| --- | --- | --- |
| surface #fffdf8 | 4.142:1 | 5.462:1 |
| canvas #f4efe5 | 3.674:1 | 4.845:1 |
| surface-muted #eee8dc | 3.451:1 | 4.551:1 |

- 静态扫描到 19 个引用规则，涵盖 card-subtitle、helper、choice-description、stat-label、batch-meta、progress-labels、empty-state 等。原型 token 同步后应对这些用途抽查，不能只测一处 h1。
- PAGE-009 注销副标题继续用已批准 `ink-soft #40585a` / `danger-soft #fae9e7`（6.473:1）；不改为 faint，也不恢复暗红说明。
- `ink-faint` 仍是视觉层级较低的文本，不豁免小字号对比度要求。访客引导 h1 是既有继承用法，记录该覆盖并维持可读性，不借此次同步重新定义整站标题色。
- 当前只完成来源核对与静态计算；主题尚未写入，原型仍是旧值。后续以浏览器实测和截图证明同步，不把既有 QA 的 BASELINE_VARIANCE 改写成通过。

## 5. 原型与设计自检计划

原型需使用可控静态日期/批次夹具，使日期输入实际改变预览，不能继续只切换状态下拉或显示固定“5 篇”。

1. 仅有早期批次 → 默认范围无命中 → 改为较早日期 → 有命中；连续“有 → 无 → 有”不丢表单或草稿。
2. 无记录、全部未参与、无效/空日期、同日边界、预览加载/失败及恢复入口并存。
3. 中英文 × 320/390/720/1280/1440：日期几何、文案换行、无横向溢出；键盘操作、状态播报和焦点保持。
4. 访客五类受限页所有状态仍是同一认证引导，没有日期表单/私有内容；抽查 Header、首页、移动导航与控制器入口。
5. 引导标题计算色等于 #596c6b；相关弱文本对比度、注销显式覆盖、两语言页面结构不回退。
6. 设计截图与运行脚本只写入 design/evidence；不修改独立 QA 结果，不使用真实账号或模型，不更新 UAT。

真实接口延迟、过期响应、服务端过滤/创建、浏览器原生日期输入和真机辅助技术仍须由后续前端与独立测试验证，不能以原型模拟替代。
