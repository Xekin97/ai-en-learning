## 2. 布局与控件的稳定性

始终保留页面标题、日期卡和预览结果卡。零命中反馈放在整个日期/结果区域下方，不替代日期输入，也不弹窗。

- 宽桌面沿用日期卡 + 320px 结果卡，间距 24px；两个日期字段等宽、44px 高、顶边对齐。局部清除第二字段的额外上边距，不改全站 field 规则。
- ≤1080px 日期卡、紧凑结果条、反馈区依次纵向排列；结果条最小 96px 高，数值 40px，与标签和词数并列，长错误文字可换行。
- ≤560px 两个日期字段纵向排列、间隔 16px；卡内起止字段仍保持相同宽高。开始按钮和空态的两个入口分别占满可用宽度，空态内边距 24px；其余断点内边距 32px。
- 反馈区与日期/结果区域间隔 24px。无额外内部滚动或固定高度；页面可自然滚动。
- 表单节点不会因预览状态变化被卸载。更新只作用于数量、状态文字、错误、反馈区和开始按钮可用状态，保留当前日期、焦点及原生日期输入的操作上下文。
- 全局语言切换可重新渲染文案，但必须先从状态恢复相同日期草稿与结果；焦点回到语言选择器，不能重置为默认范围。
- 原型面板继续悬浮，不参与产品布局。其状态名是审阅元数据，不显示在用户页面上。

## 3. 状态与动作

| 状态 | 日期与结果 | 开始新日期复习 | 恢复已有日期会话 |
| --- | --- | --- | --- |
| 最新预览有命中 | 输入可编辑；显示当前范围批次数与词数 | 可用；用户明确点击后创建 | 独立可用 |
| 最新预览零命中 | 输入可编辑；0 篇、0 词；下方空态与两个学习入口 | 禁用；不进入空会话 | 独立可用 |
| 日期未填完或不合法 | 保留原值；字段下错误；数量显示“—”，不是 0 | 禁用；不发起该无效预览 | 独立可用 |
| 结束早于开始 | 同上，错误关联结束字段；开始=结束不报错 | 禁用 | 独立可用 |
| 预览加载 | 输入可编辑；“—”及加载文字；旧命中不再用于开始 | 禁用，防止按旧结果创建 | 独立可用 |
| 预览失败 | 输入可编辑；“—”及失败说明、重试 | 禁用；不把失败当空库 | 独立可用 |
| 访客 | 原地址显示既有完整登录/注册引导，无日期/数量/私有内容 | 不提供 | 不提供 |

“独立可用”仅在已经得到合法的未完成日期会话时成立，不凭空创建恢复入口。日期错误或零命中不应隐藏或改写该会话。单篇会话继续只由学习记录恢复。

### 连续调整与重试

1. 初次进入默认浏览器本地最近 7 天，包含起止两日。
2. 编辑任一字段立即让旧预览失效；日期完整合法才重新预览。只能展示与当前草稿相符的最新结果，早期响应不得重新启用开始按钮或覆盖新范围。
3. 从有命中改为无命中，再改回有命中，始终使用同一组日期输入。空态只描述当前范围，不能改写日期或自动扩大范围。
4. 单独日期缺失时给对应字段关联错误；范围反向时关联结束字段。不纠正/覆盖用户输入值。
5. 重试保持范围，进入加载；若重试按钮因加载被移除且仍有焦点，焦点放到开始日期。若用户已移到其他控件，结果返回不抢焦点。
6. 只有当前合法且最新成功预览非空时开始按钮可用；动作处理也应有同样的保护，不能只靠 disabled 外观。实际创建仍以服务端校验为准。
7. 修改日期仅改变新会话草稿，不创建、重排、放弃或覆盖现有日期/单篇会话；普通登录成功也不自动开始。
8. 页面离开后迟到预览不得替换新页面或访客引导。进入另一任务或重新加载页面的草稿生命周期沿用既有前端方案，本修订不新增跨刷新保存。

### 空库与暂不参与

验收必须分别构造“完全没有记录”“只有较早记录”“全部暂不参与”“当前范围不匹配”。这些数据来源不同，但当前预览都可统一呈现准确的范围空态。

本次不要求新接口返回全库总量，也不根据 preview=0 宣称用户“尚未学习”。用户可直接改日期，或进入学习记录查看/调整已有批次；即使全部暂不参与，也不能将其视为被删除。

## 5. 可访问性

- 原生 date 输入，永久 Label，required；缺失或无效有 aria-invalid，与就地错误文字通过 aria-describedby 关联。
- 日期预览不把焦点移到空态；原来的输入节点保持。开始禁用有可见状态原因，不只通过按钮颜色表达。
- 独立 role=status / aria-live=polite / aria-atomic=true 播报最新结果、加载或错误，状态消息不包裹整组输入，避免每次刷新读出整个表单。
- 结果卡加载时 aria-busy=true；“—”是未知/不可用而非零，辅助文字说明具体原因。
- 空态两按钮遵循“查看学习记录 → 继续学习”DOM 顺序，手机不颠倒键盘顺序。
- 保留 44px 输入与触控目标、焦点环、自然换行；不以降低字号或负间距适配窄屏。
- 语言开关保持品牌单一显示；学习材料和 AI 标签语言不受界面切换影响。

## 6. 全局弱文本色的统一基线

当前原型已将 `--color-ink-faint` 从 `#6d7f7e` 同步为既有生产值 `#596c6b`。这是 [CR-010](../changes/CR-010.md) 已有修订在原型中的同步，不是通过修改 QA 断言掩盖差异。

| 覆盖 | 基线 |
| --- | --- |
| 所有继承 faint 的弱文本与元信息 | #596c6b；包括 card-subtitle、helper、choice-description、stat-label、batch-meta、progress-labels、model-description、empty-state 等 |
| 五类访客引导 h1 | 继续从 empty-state 继承 faint，即 #596c6b；不增加单页硬编码 |
| 访客引导正文 | 继续使用已有 ink-soft #40585a |
| 注销副标题 | 继续使用 ink-soft #40585a / danger-soft #fae9e7，不改 faint 或暗红 |
| 错误文字与主操作 | 继续专用语义色，不用 faint 代替 |
| CR-034 范围空态标题 | 局部使用 ink-soft，保持与日期卡同一辅助阅读层级 |

不透明 sRGB 静态计算：新 faint 在 surface/canvas/surface-muted 上分别为 5.462/4.845/4.551:1；注销既有组合为 6.473:1。faint 的低层级语义不免除普通文本对比度要求。使用新背景、透明叠加或不同组件时仍须按实际渲染验证，不能将这些静态数字当全站合规证明。

本轮颜色同步仅涉及 token 及其已有继承，不修改访客完整消息、图标、尺寸、布局或认证返回目标。历史 QA 的 BASELINE_VARIANCE 保留，由后续独立复验判定是否闭合。

## 7. 可运行原型与复现

本地既有设计服务：[日期空态](http://127.0.0.1:6010/prototype/?page=PAGE-007&role=learner&state=empty&locale=zh-CN)。审阅面板 PAGE-007 提供：

| 状态参数 | 夹具与操作 |
| --- | --- |
| default | 相对本地今天的 0/-1/-2/-4/-6 天各一篇；共 5 篇、14 个词条 |
| empty | 只有 -24/-20 天两篇；默认最近 7 天为 0，向前调整即可找到 |
| empty-library | 无批次；任意合法范围仍为空 |
| paused-only | 近期批次全部未参与；命中为 0 |
| resume / resume-empty | 2/5 已完成的独立恢复卡；当前预览分别有命中/无命中 |
| date-error / date-missing | 反向范围 / 空开始日期；改正可恢复预览 |
| loading / preview-error | 稳定加载 / 稳定失败状态；修改日期或重试进入实际模拟预览 |

日期变化使用 350ms 本地演示计时，随后根据夹具日期和参与标记计算投影；该时长不是产品 SLA 或后端超时。原型采用显式双语消息，状态与投影不依赖页面标题解析。

**原型限制**：这些是 PAGE-007 专用合成夹具，不改写 PAGE-005 的旧示例库。点击开始/恢复进入 PAGE-008 的既有固定教学样例，不把该样例的批次进度/总结伪装成当前预览的真实会话。真实创建、全部批次一致性、随机顺序、跨刷新恢复和 API 竞态必须在正式实现与独立测试中验证；本次不重写复习引擎或批准其通过。
