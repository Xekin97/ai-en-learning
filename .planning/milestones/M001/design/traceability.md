## 1. 追踪规则

本文件先于视觉稿建立页面、能力、数据与状态边界。原型可以使用静态示例数据演示，但不得引入未获批准的数据、指标、入口或业务操作。设计中的每个可交互控件必须能回指一个 `CAP-*`；每个内容区域必须能回指已批准的 `DATA-*` 或公开静态内容。

## 3. 跨页面设计约束

### 3.1 国际化与文案

- `DEC-023` 取代既有双语品牌并列规则：`zh-CN` 只展示“词涟”，`en-US` 只展示“WordWeave”，未来非中文界面统一展示“WordWeave”；界面语言开关仍不得重置当前任务。
- 中文和英文原型覆盖现有 12 个 PAGE 及其错误、空、流式、恢复和成功状态；英文学习短文与目标语言生成内容不随界面语言翻译。
- 首次无偏好时按浏览器首选语言顺序匹配中文或英文，无匹配使用英文；访客偏好留在浏览器，学习者与管理员偏好写入账号并跨设备生效。
- 登录时账号已有偏好优先；账号无偏好时采用当前浏览器界面语言。退出后浏览器继续使用最近选择，注销删除账号偏好但保留当前浏览器偏好。
- 账号偏好保存失败时，当前界面和浏览器选择保持，并显示可重试的就地反馈；原型面板可稳定模拟这一状态。
- 用户界面只展示任务、选择和结果，不直接展示产品验收、输入匹配算法、完整性校验、组策略或 API 调用阶段。
- 最低词数、额度结算、失败退款和答案判定继续作为产品/技术约束；只有可能造成使用次数或数据损失时，转写为一句用户可理解的后果提示。

### 3.2 短文 Tag 归属

- `DEC-009` 与 `DEC-021` 要求每个生成批次只有一组 1–3 个短文 Tag，语言等于当次释义目标语言。
- PAGE-004 在完整结果的阅读区展示一次短文 Tag；PAGE-005 在批次行展示同一组 Tag；PAGE-006 在短文头部展示同一组 Tag。
- 每个词条资源只展示情境释义和提示短语，不拥有 Tag；搜索仍只按目标词条，不扩展为 Tag 搜索。
- `CR-002` 已解决：DATA-011/012 与 AI 输出契约都把 Tag 放在短文根层，DATA-013 不再拥有 Tag；设计与上游结构一致。

### 3.3 身份与导航

- 访客与学习者共用公开/学习者信息架构；访客访问 PAGE-005、PAGE-007、PAGE-009 时必须看到登录原因和返回意图。
- PAGE-004 以 DATA-005 关联访客的滚动额度和单活跃生成请求；匿名标识本身不在界面显示、编辑或作为用户操作入口，界面只呈现剩余可用次数与请求状态。
- 管理员与学习者共用 PAGE-003，但认证后进入独立管理员壳层；管理员侧只包含 PAGE-101、PAGE-102、PAGE-103，不设计仪表盘或学习入口。
- 用户侧和管理侧视觉语言保持同源，但导航与权限必须明显分离，避免管理员误以为能编辑用户内容。

### 3.4 AI 状态

- DATA-011 流式内容始终标记为“临时生成中”；CAP-010/011 的保存操作必须在完整校验通过后才出现或启用。
- 主动取消需要在操作前或附近说明会消耗额度；系统/网络失败需要说明本次额度已返还。
- 页面离开提示只能说明结果会丢失，不能暗示支持恢复。
- 模型名称/说明可见，DATA-008 原始模型 ID 与 DATA-007 密钥不进入学习者界面。
- PAGE-004 的 DATA-001 候选列表锚定词汇搜索框并以浮层展示，不参与配置栏文档流，也不得推动 DATA-002 已选词条或四项配置；候选过多时仅在浮层内部滚动。

### 3.5 复习状态

- CAP-018 与 CAP-019 不在任何错误、跳过或总结状态显示正确答案。
- 阶段一明确写出“填写词库原始词条”，提示短语开关每次进入默认关闭。
- `DEC-032` 已关闭 `CR-006`：提示开启后，短语中属于当前目标词条的全部已记录位置同时遮蔽；多个空仍只映射一个原始词条输入，任一可见或可访问内容都不保留同目标答案。
- `DEC-035` 已关闭 `CR-015` 并形成 `CR-016` 的设计输入：阶段二按正文首次出现建立内部同源关系，视觉随机分配颜色并叠加纹理；正常界面不显示组号。每个 occurrence 独立填写实际表面形式，焦点联动和仅辅助技术可读的匿名组名在颜色不足时继续成立。
- 页面同时表达会话批次进度和批次内部阶段进度；中断只保留已完成批次。
- `DEC-024` 与 CAP-022 已关闭 `CR-004`：PAGE-005 的每个未删除批次都显示本篇复习操作，checkbox 未勾选时入口仍存在。
- 同一批次有未完成单批次会话时，PAGE-005 的操作文案表达“继续本篇”；没有时表达“复习本篇”。完成后再次进入创建新一轮，不把旧结果伪装成未完成进度。
- PAGE-007 只展示并恢复日期范围会话；PAGE-008 以“本篇复习 / 日期复习”短标签、相应批次数和相应返回入口区分来源，不暴露内部会话模式字段。
- 两种路径共用答题卡、提示、判错、跳过和不显示答案规则；切换到单批次路径不得清除原日期范围会话的示例进度。

### 3.6 数据与破坏性操作

- “参与复习” checkbox 是可逆状态：勾选表示进入后续复习范围，取消勾选只把批次排除在自动范围外；“永久删除批次”和“注销账号”是不可恢复操作，视觉和文案层级不得混淆。
- PAGE-005 的六项 DATA-016 是平铺全量统计，不转化为趋势图、日期图表或新增指标。
- PAGE-103 的 DATA-012/013 始终只读，不设计暂停、恢复、删除、编辑或冒充入口。
- PAGE-103 结果列表只投影 DATA-003、DATA-004、DATA-006 与 DATA-009 所需的账号摘要，不投影 DATA-012/013 的学习数量或内容；学习内容仅在管理员明确进入用户详情后以只读方式出现。

## 4. 原型覆盖策略

浏览器原型需让用户从右下角悬浮“原型面板”切换全部 12 个 PAGE；面板脱离文档流，不改变被审阅页面的尺寸，并至少实际操作以下关键路径：

1. PAGE-001 → PAGE-004：选词（候选浮层不改变配置栏高度）、四项显式配置、流式生成、取消/失败/有效结果、保存或访客认证承接。
2. PAGE-005 → PAGE-006 / PAGE-008：查看六项统计、词条搜索、参与复习 checkbox、从勾选或未勾选批次开始/恢复本篇复习，以及永久删除确认。
3. PAGE-007 → PAGE-008：只恢复日期复习；验证它与本篇复习分别保留入口和进度，并覆盖阶段一重复目标提示的全部遮蔽与单次输入、判错，以及阶段二同源随机颜色/纹理/焦点联动、各 occurrence 独立作答、部分错误与布局安全、批次与模式对应总结。
4. PAGE-002/PAGE-003/PAGE-009：注册、登录意图、改密、退出和注销二次确认。
5. PAGE-101 → PAGE-102 → PAGE-103：密钥/模型、四组策略，以及用户搜索前/加载/多结果/单结果/无结果/错误/继续加载/详情返回、换组、重置密码和只读学习库。
6. 任一用户页与管理员页：中文/English 双向切换、品牌随界面语言单一显示、当前任务状态保留、界面语言与释义语言相互独立。

其余错误、空和权限状态可以通过原型状态切换器稳定复现；状态切换器属于设计验收工具，不代表正式产品能力。
