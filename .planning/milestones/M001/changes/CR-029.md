# 学习者首页、复习日期与注销文案偏离批准设计

## 问题与证据

- 用户本轮 UAT 第 1–3 项；[复现记录](../verification/evidence/uat-detail-regressions-2026-09-05.md)。
- PAGE-007 桌面 From 为 379×54px，To 为 379×44px；第二个 .field 继承 20px margin-top，原型显式清零。手机端虽同高，第二字段仍多出 20px 间距。
- PAGE-001 已登录英文主操作为 Start review，原型为 Review；中文文案一致，不应无差别改中文。
- PAGE-009 英文危险区副标题为 This action cannot be undone.，原型为 This can’t be undone.；正文也使用了不同的 reviews/account information 表述。

2. 首页按已登录/访客分别匹配原型，英文已登录为 Review；不得用同义文案替代。
