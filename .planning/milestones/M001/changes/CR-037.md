# UAT079：认证提示位置与本人改密英文文案偏离设计

## 发现的问题

- CR037-01：从 Review 的登录引导进入认证卡片，提示应在标题前、是首个元素并带 role=status；实现放到标题/副标题后且缺少该语义。注册页同源问题。
- CR037-02：/account 的 Change password 弹窗中，本人确认辅助说明、会话说明、主按钮三处英文与原型不同。该场景不是管理员 Reset password。

## 证据与来源

- CONFIRMED：用户UAT报告两项不一致，并表示本次没有发现其他不一致。
- [逐项原始质量报告](../verification/uat-079-feedback.md)、[双引擎实际结果与32+8张截图](../verification/evidence/uat-079-feedback/results.json)。
- [批准设计](../reviews/uiux-design-cr031-cr032-revision.md)、[原型 app.js](../design/prototype/app.js) renderAuth / showPasswordDialog、[原型 i18n.js](../design/prototype/i18n.js)、[设计主题](../design/theme.css)。
- 追踪：PAGE-007 → PAGE-003/002（关联 PAGE-005/006/009 返回目标），PAGE-009；CAP-002/003/004/021；DATA-003/004/018；API-002/003 不变。
- 复现：未登录 /review → Sign in and continue → /login，再去注册；专用学习者 /account → Change password，仅打开即可看到差异。
- 65 PASS / 60重复矩阵FAIL / 0ERROR；两个问题均实测，不是新设计意见。

## 建议变更

PROPOSED，仅前端既有设计对齐：

1. 按原型移动登录和注册卡片的提示到正确 DOM 位置并恢复 role=status，保留既有语言/返回意图/claim逻辑和样式；不通过视觉重排隐藏语义偏差。
2. 将三处英文对齐原型：Confirm it’s you；Your current session will stay open. Other sessions will be signed out.；Update password。其余已一致文本不任意重写；检查 shared account.confirmPasswordCopy 的注销弹窗消费者。
3. 测试补齐认证提示位置/语义和本人改密完整字面文案，不只测存在性或管理员密码接口。中英文、390/1440、Chromium/WebKit；安全返回、错误、取消、焦点、合法改密/会话语义按质量报告执行。
4. 保持 application/映射/状态/展示分层；不改产品、设计、API、密码策略或数据库。

## 不变更的影响

用户 UAT 的两项明确偏差未关闭，不能把上一轮局部测试通过当作完整 UAT 通过。与这两项无关的已闭合CR保持结果，不反复推翻。
