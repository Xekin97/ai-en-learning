# 从学习记录直接发起单批次复习

## 发现的问题

已批准的产品契约只允许学习者先进入 PAGE-007 选择日期范围，再由系统创建包含多个活跃批次的复习会话。用户在 UI/UX 审阅中新增要求：学习者应能在 PAGE-005 学习记录中直接选择某个批次，并立即进入该批次的 PAGE-008 复习过程。

同轮审阅还指出，PAGE-005 以“暂停 / 继续”按钮表达批次是否进入后续复习范围，语义不够直接。该既有状态不变，但 UI/UX 将把控件统一改成标有“参与复习”的 checkbox：勾选对应活跃，取消勾选对应不再复习。

## 证据与来源

- 上游产物：`product/abilities.md` 的 CAP-012、CAP-015、CAP-017 至 CAP-020；`product/data-assets.md` 的 DATA-012、DATA-014、DATA-015；`product/pages/index.md` 的 PAGE-005、PAGE-007、PAGE-008。
- 当前设计：`design/prototype/app.js`、`design/interactions.md`、`design/traceability.md`。
- 用户最新要求：学习记录可以直接打开某个批次的复习过程；“暂停 / 继续”改为“参与复习” checkbox。

## 建议变更

1. PAGE-005 的每个批次增加清晰的“复习本批”操作；触发后不经过 PAGE-007 日期范围，直接为该批次创建一次单批次 DATA-014 并进入 PAGE-008。
2. 单批次会话继续执行既有两阶段复习、答案不显示、错误重试、跳过、结果写入和中断恢复规则；批次内词条顺序仍在创建时随机并固定。
3. PAGE-007 继续承担按日期范围发起多批次复习，不被新入口取代。
4. 推荐把“参与复习”仅定义为是否被日期范围的批量复习自动选中；即使未勾选，用户仍可显式点击“复习本批”。这样既尊重排除自动复习的意图，也不阻止一次主动回顾。
5. CAP-015 与 DATA-012 的底层状态保持不变，只把 PAGE-005 / PAGE-006 的用户可见控制改为 checkbox，并采用结果导向反馈。

## 不变更的影响

如果 UI/UX 直接增加入口而不补充产品能力，技术设计无法确定单批次会话是否仍属于 DATA-014、如何恢复和写入 DATA-015，也无法判断“不参与复习”的批次能否被用户主动复习。继续使用“暂停 / 继续”按钮则会保留用户已经指出的理解障碍。

## 路由建议

- 应返回的责任阶段：`product-planning`。
- 是否阻塞当前工作：阻塞 PAGE-005 至 PAGE-008 新路径的设计和 UI/UX 最终验收；不阻塞“参与复习” checkbox 对既有 CAP-015 的表达修订。
- 需要用户决定的问题：未勾选“参与复习”的批次是否仍允许通过“复习本批”主动复习；UI/UX 推荐允许。

## 解决记录

`RESOLVED`（2026-08-29，`product-maya`）：

- 用户通过 `DEC-024` 确认 PAGE-005 为本人所有、未删除批次提供直接复习入口，且未勾选“参与复习”的批次仍可主动复习。
- “参与复习” checkbox 只控制 PAGE-007 日期范围会话的自动选入资格；取消勾选不删除内容、历史或主动复习能力。
- DATA-014 已扩展为日期范围与单批次两种会话模式；单批次会话不保存日期范围，并与未完成日期范围会话相互独立。
- 同一批次存在未完成单批次会话时优先恢复，不重复创建；完成后再次进入才新建一轮。
- `overview.md`、`data-assets.md`、`abilities.md`、`pages/index.md` 与产品交接单已同步；新增 CAP-022，未新增 PAGE 或 DATA。
- `ai-behavior.md` 无需语义修改：本变更不改变 AI 输入、输出、额度、模型或生成安全边界。
- UI/UX 仍需补齐 PAGE-005 → PAGE-008 的直接复习入口、两种会话模式反馈及回归验证。
