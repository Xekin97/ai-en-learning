# 登录后未立即采用账号界面语言

## 问题与证据

真实 UAT 6001 上，将专用管理员账号偏好保存为 zh-CN（PUT ui-locale 200），退出，在英文登录页重新登录：bootstrap 的 ui_locale=zh-CN，但页面 html.lang=en-US；刷新后才显示中文。镜像为 0cb4bceb3555。此前 Models/Plans 的跨硬导航语言差异源于此，不能作为单纯的测试等待问题忽略。

## 批准依据

- design/interactions.md「全局多语言」及「登录」：登录时账号值优先，无值时采用浏览器语言，品牌同步。
- PAGE-003；CAP-003；DATA-018；既有 API 登录响应的 ui_locale。
- 原因定位：根 app 只在初次启动初始化语言；登录已更新应用 session，却在导航前没有应用账号偏好。

## 验收

1. 学习者、管理员从相反语言的登录页登录后，无需刷新即应用账号语言。
2. 中文只显示词涟，非中文只显示 WordWeave；刷新后语言一致。
3. 保留登录返回意图、访客承接、DTO→应用模型→渲染边界；不修改 API 或设计。
4. 用户 UAT 12 项原返工矩阵保持通过。

## 路由

implementation / frontend-claire。无新增产品或设计决策，按持续开发—测试授权修复。
