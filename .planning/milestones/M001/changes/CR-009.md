# 前端关键页面偏离已批准入口、确认、统计与复习来源契约

## 发现的问题

真实浏览器验证发现多项已批准且用户可观察的前端行为未落地。核心生成与复习 API 可以工作，但关键入口、状态解释和破坏性操作确认与产品/UI 真源不一致。

1. PAGE-001 首页主操作区只有“立即学习 / 开始复习”，缺少“学习记录”第三入口。
2. PAGE-004 在生成已经完整校验、尚未保存时点击导航会直接离开，没有放弃确认；当前路由守卫只覆盖 `streaming`，未覆盖 `valid`。
3. PAGE-005 即使补平后端分页契约，也只渲染 4 项统计，缺少“暂不参与复习批次”和“曾成功复习批次”两项。
4. PAGE-008 单批次复习没有“本篇复习”来源标签，顶部返回链接固定为 `/review` 而不是学习记录 `/library`。
5. PAGE-009 中文基础权益名称显示内部组语义“正式账号”，没有使用已批准的学习者文案“基础版”。
6. PAGE-103 换组表单直接提交，没有要求显式确认；密码重置表单同样没有确认步骤或确认状态。
7. PAGE-004 的配置控件模板使用 `button.choice`，主要 CSS 却只样式化 `.choice label` 与 `input:checked + label`，导致浏览器默认按钮样式、当前选中态不清楚，模型名称与说明发生视觉黏连。生成结果的资源标签和值也缺少视觉分隔。

## 建议变更

1. 按 CAP-001 恢复首页第三入口，并让访客沿受限意图进入登录流程。
2. PAGE-004 路由离开守卫同时覆盖 `streaming` 与 `valid`，区分被动流中断和已验证结果放弃；取消导航时保留当前结果。
3. PAGE-005 平铺呈现 DATA-016 六项统计，不新增趋势或派生指标。
4. PAGE-008 从 session mode 派生用户可读来源标签与返回路径：单批次为“本篇复习”并返回 PAGE-005，日期范围为“日期复习”并返回 PAGE-007。
5. 学习者侧将 `basic` 映射为“基础版”；内部组代码和管理员配置语义不得直接成为学习者文案。
6. PAGE-103 在换组和密码重置前展示后果确认，确认后才发送 `confirmed:true`；取消不得产生写操作。
7. 对齐配置控件 DOM 与 CSS，提供清楚的默认、hover、focus、selected、disabled 状态，并修复模型说明及学习资源标签/值的间距与换行。
8. 增加连接真实后端的浏览器回归，不只使用 mock response；回归需覆盖中文、英文、320px 和桌面。

## 不变更的影响

- 首页不能按产品定义承载三条主任务路径。
- 用户可无意丢失一次已验证但未保存的 AI 资源。
- 学习统计和单批次复习来源不完整，用户难以理解当前上下文。
- 管理员高影响操作缺少必要防误触保护。
- 配置控件虽可点击，但视觉状态不足以让用户确认本次生成配置。

## 路由建议

- 应返回的责任阶段：`implementation`，由前端实现角色按现有产品/UI 真源修复；无需重开产品或 UI/UX。
- 是否阻塞当前工作：是；阻塞关键用户路径和管理员 UAT。
- 需要用户决定的问题：无，预期行为均已批准。

## 解决记录

- 2026-09-02 由 `frontend-claire` 完成修订：恢复首页“学习记录”入口；生成中的流和已校验未保存结果均受离开保护；取消离开保留结果，确认放弃调用 discard 后再导航；访客登录承接不重复弹窗。
- 学习记录现平铺 DATA-016 全部六项统计；单批次复习显示“本篇复习”来源、批次上下文并返回 `/library`；学习者 `basic` 显示为“基础版”。
- 管理员换组与密码重置均在发送写请求前要求显式确认，取消不会写入；造文配置按钮补齐默认、hover、focus、selected、disabled 状态，模型说明与资源标签/值已分隔。
- 自动化证据：`pnpm test:e2e` 桌面/移动端 12/12 通过；隔离 Compose 真实纵向链路 `live-e2e.mjs` 20/20 通过，其中含真实 PostgreSQL、backend、Nuxt SSR、Nginx 与确定性 OpenRouter 模拟服务。
- 结论：建议项 1–8 已全部实现，CR-009 关闭；最终里程碑结论仍由 verification 角色给出。
