# 学习批次标题可编辑及热门预设字段简化

## 授权与来源

用户明确要求：“返回产品角色调整需求，所有的学习批次短文，标题均可由用户自行编辑，默认标题和现有，热门预设里的文章，也不再区分不同语言的标题，同时移除说明字段”。[TRANSITION-M002-005](../reviews/title-fields-rollback.md) 已正式激活 product/to-c / product-maya，处理本次修订；没有自动批准新稿或切回设计。

当前输入为已获 TRANSITION-M002-004 批准的 M002-PRODUCT-02 完整产品基线。修改前原件见[输入快照](../product/evidence/M002-PRODUCT-03-inputs.tar.gz)，来源与保护摘要见[来源记录](../product/evidence/M002-PRODUCT-03-sources.json)。UI-05 保留为修改前设计，本次不改原型或应用。

## 变更范围与当前规则

1. D2-81 / CAP-220：学习者可编辑本人所有已收录学习批次的标题，包括一期保留批次、普通生成批次及预设生成后收录的批次。默认标题沿用现有目标词顺序以 ` · ` 连接的规则，例如 `resilient · wander · weave`。本人修改后持久保存，界面语言切换不改写标题。
2. 标题是批次的普通文本信息；详情提供编辑、保存和取消，拒绝空白，失败可重试。英文正文、目标资源、生成配置快照及复习答案规则保持；管理员对用户学习内容仍只读。批次删除、账号注销覆盖标题。
3. D2-82 / CAP-218：每篇热门预设仅一个标题，中文与英文 UI 均显示同一值；移除预设说明字段，不再配置、展示或校验中英文标题/说明。保留管理员生成样文及其预览、英文正文、释义语言和完整锁定配置。
4. 预设仅改标题时可沿用对应生成配置的有效预览，但仍保存草稿后手动发布。用户收录后的私人批次与公开预设标题分别管理，互不回写；新收录批次仍使用原词条默认标题。

现有默认值的只读核对依据：`frontend/app/pages/library/index.vue` 的 `batch.entries.join(" · ")` 与 `frontend/app/pages/library/[batchId].vue` 的目标词连接展示。AI 短文契约不包含模型生成标题，本修订不增加标题生成调用。

## 影响与继承

- 资产：DATA-012 增加可编辑标题语义；DATA-212 单标题并移除说明；无新数据资产类型。
- 页面：PAGE-005 列表显示最新标题、PAGE-006 详情提供编辑、PAGE-103 管理员只读最新标题；PAGE-212/217/216 调整预设管理、目录及工作台展示，无新增页面。提交前复习不因标题或默认词条标题泄露标准答案。
