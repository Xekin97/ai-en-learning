# M002-UI-32-R3 响应式与无障碍

有效规则见 [规格](design-spec.md) / [theme.css](theme.css)。继承当前产品完整页面，词标题、释义、用法与学习卡层次保持。

- 可见播放控件按 18×18px 图标布局，无边框、底色、阴影、内外边距；多音源名称按内容宽度紧跟，间隔 8px，不再保留 44px/66px 的布局块。单音源没有文字空白占位。
- 通过绝对定位透明伪元素保留点击范围，不增加可见尺寸或排版高度。单音源为 44×44px；多音源主图标为 26×44px，标签点击范围为内容宽度 + 8px、高 44px，两个范围在 8px 间隔的中点相接、不重叠。此处替代旧版所有按钮固定 44px 宽的设计约束。
- 仅键盘 focus-visible 显示焦点环；这不是常驻边框。展开后的音源菜单仍保留原卡片表面和选项间距以便辨认，本次收紧的是行内控件。
- 桌面保持双列词义/文章侧栏，390 手机单列，320 长词可换行。图标切换不改卡片高度，不遮词义，不以省略号缩短目标词。
- 无可见操作/状态文字，包括 hover tooltip；也不在旁边、底部、全局状态条补写。多音源名称是选择项信息，只有此类文字可以显示在控件中。
- button 仍有包含当前词、动作/必要来源的 aria-label；非可见 role=status / aria-live=polite 在本控件内播报，不要为去掉视觉文案而删掉无障碍语义。
- 加载圈、声波、重试箭头、警示、扬声器形状区分各状态，不仅靠颜色/动画。reduced motion 停止旋转/脉动/过渡，保留图标形状。
- Tab/Enter/Space 使用真实按钮。音源选择用 aria-haspopup/expanded/controls，选项为 menuitemradio/checked；上下/Home/End 导航，Escape 关闭回焦；选定后回播放按钮。播放不是 aria-pressed 开关，同词再次点击从头播放。
- 口音不可用时点击警示图标只展开既有选择菜单，必须显式选择另一项才更换音源。失败和手势重试继续在同一按钮，状态改变不抢焦点。
- 卡片/触控尺寸检查允许小于 0.01 CSS px 的浏览器浮点舍入，不允许状态引起可见位移或相邻点击区域重叠。

文案来自 copy.json；样例文章/词义维持原书店 fixture 的语言。设计键盘/DOM 检查不证明真实读屏软件或设备发声兼容性，OPEN-403 留给技术验证。
