# M002-UI-32-R3 交互与 Motion

有效范围见 [规格](design-spec.md) 与 CR-314。状态只改变原位图标，不渲染操作/状态文字、标题 tooltip 或独立提示。单音源没有来源/口音文本，多音源只有音源名称与菜单。

| 状态 | 18px 主按钮图标 | 点击结果 |
|---|---|---|
| idle / complete | 扬声器 | 播放/从头重播当前词 |
| preparing | 转圈 | 重新发起当前词；新词取代旧词 |
| playing | 声波线 | 从头重播，不做停止开关 |
| error | 重试箭头 | 重试当前词 |
| gesture | 重试箭头 | 在直接手势下再次播放 |
| accent | 圆形警示 | 打开当前音源选择菜单，聚焦可替代项；不自动换源 |

原型口音失败样例为英音失败、可改美音。用户点菜单中的美音后才切换播放；因为按钮已无动作文字，不能沿用 R1“点原按钮立即换源”的隐藏含义。无替代项时进入 error。非可见 aria-label/live 给出完整原因与下一动作，始终留在本词控件内。

至少两个实际可选音源时，显示当前名称（样例为英音/美音）和菜单段。单音源即使已知英音/美音也不显示该标签；词典优先/浏览器兜底不是自动新增的两个选择项。失败或回退也不在单音源按钮旁添加“词典”“浏览器”等来源文案。实际播放路径仍用于无障碍描述与后续技术验证。

菜单紧贴控件右下方。点击/Enter/Space 打开并聚焦选中项；上下/Home/End 导航；选择后播放且焦点回播放图标；Escape 关闭并回菜单触发器；外点/焦点离开关闭。手机保持就地菜单。

同页只一条活动播放。跨词取消旧请求/声音，同词重播从头，旧结果不可抢播；旧控件恢复扬声器。离页、目标移除/替换需取消真实音频与语音。原型仅用定时器/序号演示，生产语义由 OPEN-403 确认。

主按钮按 18px 图标布局，标签按内容宽度布局；无边框、底色、阴影和内外边距。状态切换不改卡片高度。颜色 160ms；加载图标 900ms 旋转，声波 920ms 轻微脉动，菜单 180ms 淡入/小位移，缓动见 theme.css。减少动效关闭所有循环/过渡，图标形状继续区分状态。无打字/文字播报动画。

设计演示准备 420ms、播放 1800ms，仅用于复现，不代表生产超时或真实音频时长。真实许可、音频、网络和设备支持未验证。
