# M002 完整页面职责修订稿

> 下文为越界操作的原内容，保留供核查；其完整性及规则整合未经产品角色验收。

## 全局导航与承接

公开/学习者 Header：简洁首页、普通造文、复习库、按日期复习、独立试用目录。访客提供登录/注册；受限入口保留目标意图。头像菜单为个人信息、账号成长、道具卡、兑换中心，四个页面共用左侧基础信息；Header 无学习成长入口。

后台固定八模块：概览、数据分析、模型管理、计划管理、用户管理（等级/积分/学习记录）、成长运营、首页预设、消息管理。消息独立，模型与计划独立；不因重组丢失一期功能。

页面职责不等于路由数量。当前保留七个一期职责，加十六个二期职责，共 23 个；设计拆分为 28 个视图。旧 PAGE-001/004/009/101/102 分别映射 PAGE-205/204/206/208/208，不形成两套并行规则。

## 继续存在的一期页面

### PAGE-002 注册

- **角色**：访客。
- **目标**：创建学习者账号，并在需要时承接访客的待保存结果。
- **数据**：创建 DATA-003、DATA-004、DATA-018；可消费 DATA-017。
- **能力**：CAP-002、CAP-011、CAP-021。
- **主要区域**：用户名、密码、确认密码；规则提示；提交；转到登录；存在待保存结果时显示“注册后保存当前内容”的明确上下文。
- **关键状态**：默认、字段错误、用户名占用、提交中、成功；承接仍有效/已丢失。
- **离开路径**：认证后返回 PAGE-204 完成承接，或进入 PAGE-205。
- **验收**：不出现邮箱、手机和年龄字段；失效的待保存结果不会被误报为已保存。

- 承接成功后进入已收录批次或复习库，先保存再提醒；注册不新增邮箱/手机验证或自动生成。

### PAGE-003 登录

- **角色**：访客、已退出用户。
- **目标**：建立会话并按角色或原意图继续。
- **数据**：读取 DATA-003、DATA-018，创建 DATA-004；可消费 DATA-017。
- **能力**：CAP-003、CAP-011、CAP-021。
- **主要区域**：用户名、密码、登录；转到注册；存在待保存结果或受限页面意图时说明登录后的去向。
- **关键状态**：默认、凭据错误、提交中、成功、待保存结果已丢失。
- **离开路径**：学习者回原目标、PAGE-204 或 PAGE-205；管理员进入后台概览（PAGE-213）。
- **验收**：不提供“忘记密码”自助流程；不能在页面选择角色或组别；错误不暴露账号是否存在。

### PAGE-005 学习记录

- **角色**：学习者。
- **目标**：查看全量统计并找到、管理所有当前保存批次。
- **数据**：读取 DATA-002、DATA-012 至 DATA-016、DATA-018；可更新或删除 DATA-012 及关联数据，可恢复或创建单批次 DATA-014。
- **能力**：CAP-012、CAP-013、CAP-015、CAP-016、CAP-020、CAP-021、CAP-022。
- **主要区域**：六项统计摘要；词条搜索；从旧到新的批次列表及短文级标签；“参与复习” checkbox；打开详情、直接复习本批、删除操作。
- **关键状态**：首次空状态、正常列表、搜索无结果、参与状态切换、单批次新建/恢复/不可用、删除确认、删除成功/失败。
- **离开路径**：PAGE-204、PAGE-006、PAGE-007、PAGE-201、PAGE-206。
- **验收**：默认顺序始终从旧到新；搜索仅按目标词条；暂不参与日期范围复习的批次仍可见且可直接复习；同批未完成单批次会话优先恢复；删除必须明确确认且不会暗示可恢复。

### PAGE-006 批次详情

- **角色**：学习者。
- **目标**：完整回看一个保存批次并管理其复习状态或删除。
- **数据**：读取 DATA-012、DATA-013、必要 DATA-202、DATA-018；可更新/删除 DATA-012。
- **能力**：CAP-014、CAP-015、CAP-016、CAP-021。
- **主要区域**：保存时间与“参与复习”状态；模型用户可见名称、语言、场景、长度；短文级标签与完整短文；已保存的原词释义和提示短语；参与复习 checkbox、永久删除。
- **关键状态**：正常、无权访问、已删除/不存在、操作确认。
- **离开路径**：返回 PAGE-005、前往 PAGE-007、PAGE-204。
- **验收**：内容只读且配置为生成时快照；模型停用不影响显示；其他账号不能通过地址访问。

### PAGE-007 复习范围

- **角色**：学习者。
- **目标**：选择复习日期范围、了解命中内容，并开始或恢复日期范围会话。
- **数据**：读取 DATA-012、DATA-014、DATA-202、DATA-018；创建 DATA-014。
- **能力**：CAP-017、CAP-020、CAP-021。
- **主要区域**：默认最近 7 天的开始/结束本地日期；包含边界提示；参与日期范围复习的批次命中数量；开始复习；如有未完成日期范围会话则提供恢复及进度摘要。
- **关键状态**：有可复习批次、无命中、无学习记录、日期错误、有可恢复会话。
- **离开路径**：PAGE-201、PAGE-005、PAGE-204。
- **验收**：只统计勾选“参与复习”的批次；创建会话时固定两层随机顺序；空范围不进入空白复习页；PAGE-005 创建的单批次会话不在此处覆盖或替代日期范围恢复入口。

### PAGE-008 本轮复习完成概况

- **角色/目的**：学习者了解刚完成的日期范围或单批次会话的最小完成概况。
- **数据/能力**：DATA-014/202，CAP-020/022/203/204；不保存或回放逐题答案。
- **区域/路径**：完成批次数、成功/未成功尝试与跳过概况；返回复习库、重新选择日期、继续造文。
- **状态/验收**：单批次/多批次、全部完成、内容已删除；已完成批次不重复进入，提交后离开不能借此页面恢复历史答案。旧 PAGE-008 作答与单批总结职责由 PAGE-201/202/203 承接。


### PAGE-103 用户管理

- **角色**：管理员。
- **目标**：按用户名定位账号，处理换组、密码重置并只读查看学习库。
- **数据**：读取/有限更新 DATA-003、DATA-004、DATA-006、DATA-009，读取自己的 DATA-018；只读 DATA-012、DATA-013、必要 DATA-202。
- **能力**：CAP-003、CAP-021、CAP-104、CAP-105、CAP-106、CAP-107。
- **主要区域**：用户名搜索与结果；用户角色/组别；换组确认及额度重置说明；直接设置新密码及会话失效说明；含短文级标签的只读批次列表和详情；退出。
- **关键状态**：无结果、用户详情、换组确认/成功、重置密码确认/成功、学习库空状态、只读详情。
- **离开路径**：PAGE-208、PAGE-208、PAGE-003。
- **验收**：没有冒充、删除账号、修改/删除/暂停用户内容或授予管理员入口；直接调用对应越权操作也被拒绝。

- 二期同模块包含用户等级进度、积分余额/流水与正数补发（PAGE-211），以及只读学习记录；基础计划调整只重置该计划，保留其他体验及奖励。

## 全局体验约束

- 全局最大内容版心支持 1440px，具体阅读宽度、列数、控件密度交设计决定。
- Header 承载消息入口与用户身份，不展示称号；成就和称号仅在个人中心，成长模块在个人中心内的具体布局由设计安排。不要把数据库 ID、模型内部标识或流水实现细节放入普通用户决策流程。
- 后台操作需成功/失败反馈；签到自动到账、成就/等级达成待领及成功领取积分/经验/道具有可理解的反馈，成就/称号展示集中在个人中心；不要用 toast 代替必须明确确认的高档覆盖损失。
- 继承现有中英文 UI 与语言切换保持任务规则。运营消息、成就/称号和道具名称/说明支持中英文分别配置；D2-76 缺少当前界面语言版本时显示已有另一语言，不自动翻译。UI 文案、英文学习内容和 AI 释义目标语言分开；不因本次 UI 更新增加语种。
- 正误不能只靠颜色表达：已有删除线/正确答案对照与设计提供的可读状态共同说明结果。输入、通知与确认流程应支持键盘和辅助技术。

产品规则已明确，具体 SVG、图标、字号、动画时长、断点和路由命名由设计产出。PAGE-216 的独立入口及只读配置、PAGE-201 的填写顺序与全局 1440px 上限是明确约束。

按页面关联的能力和 AC 设计正常、空态、失败及恢复状态。重点核对 CAP-204 草稿恢复、CAP-209/210 登录呈现、CAP-214 手动领奖与降级资格、CAP-215/216 两类期限和逐模型到期、CAP-217 配置历史效力、CAP-218 草稿发布及预设例外、CAP-219 指标口径。业务正文见[能力与验收](../abilities.md)，确认依据见[决策记录](../../../decisions/product-decisions.md)，不从历史建议恢复已撤销的功能。

## 必须连通的路径

1. 普通选词/配置 → 流式生成 → 有效完整资源 → 收录 → 复习库 → 批次详情。
2. 访客试用或普通生成 → 登录/注册 → 一次性收录 → 消息正文提醒 → 后续学习；失败可重试，丢失明确提示。
3. 复习库任一未删除批次 → 单批次会话；参与复习开关关闭也可进入。
4. 日期范围 → 命中数量 → 固定随机多批次会话；与单批次会话独立。
5. 两种会话 → 填写/回退 → 随时概览/修改 → 提交 → 当次正误总结 → 重来/下一批/本轮概况。
6. 有效生成自动签到；全对复习新增去重掌握；成就/升级手动领奖 → 道具/兑换 → 权益生效/到期/符合条件的模型卡退积分。
7. 用户本人删除内容/注销和管理员只读查看严格区分；账号改密、退出与管理员重置密码有各自会话失效范围。
