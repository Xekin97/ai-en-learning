# 首版浏览器朗读合同

本补充依据[用户选择B](../evidence/backend-followup/scope-decision.json)，覆盖[旧合同](index.md)的双路径编排；API-401从首版撤下，API-402成为唯一播放路径。旧合同保留为历史。工程预算复用已接受的FE-PRON-01及TA1；尚无应用实现。

## 关联范围与权限

CAP-401～404，DATA-401/403/404，PAGE-402计划/结果词义卡片、PAGE-403已保存文章词条。DATA-402外部录音候选不再需要；不改变已批准的无持久化数据方案。PAGE-401选词仍排除，游客/普通/付费用户均免费，不扣额度。

调用者是当前可交互词卡的客户端协调器。SSR只渲染稳定图标，浏览器对象不进入Nuxt payload/DTO/数据库。无后端HTTP路径、认证、密钥、队列或服务端请求；当前词条读取的既有页面授权规则照旧。

## 输入

| 字段 | 必填及约束 |
| --- | --- |
| entry | 必填；当前卡片原词，非空，至多128个Unicode码点；拒绝控制字符、换行、URL形式，不改写原卡片；沿用既有空格、连字符、撇号处理 |
| attempt/surface/session token | 必填；识别本次点击、当前卡片表面及会话，仅页面内存，不发送外部 |
| selected option | 可选；用户明确选择时的实际voice/locale句柄；必须在每次播放前复核，不依据名称推导口音 |

只把entry交给`SpeechSynthesisUtterance`，不发送释义、用法、文章、账号或模型信息。浏览器声音可以是本地或浏览器平台的远程服务，不承诺离线或特定Google声音；不另接Google Cloud/Translate API。

## 成功事件与失败

本合同非HTTP，没有HTTP成功码。`speak()`返回不表示发声成功；以当前令牌对应的`start`进入播放中，以`end`进入完成。实际声学听音另验，事件不能代替人工确认。

| kind | 条件 | 客户端处理 |
| --- | --- | --- |
| unsupported / no_english_voice | 接口不存在，或声音就绪预算后仍无英文声音 | 本词原位失败图标，可手动重试；不请求麦克风、不新增安装指引 |
| accent_unavailable | 选定口音消失而有其他实际选项 | 依已批准TA1显示原位替代选择；不自动切换、保留准确失败口音快照 |
| gesture_required | not-allowed或明确手势限制 | 原位重试；下次点击直接复核voice并speak |
| start_timeout / end_timeout | 分别达到2秒/12秒截止时间 | 令牌失效、cancel、清理，进入原位失败；不自动循环重试 |
| failed | network、synthesis-failed、非主动中断等 | 有限失败；不展示原始平台报错或另找音源 |
| cancelled | 新播放、退场、离页、删除或会话失效 | 静默取消旧尝试，丢弃迟到事件，不触发替代播放 |

显示和无障碍文案仍以设计真源为准，不由本合同新增可见操作/状态文本。

## 行为规则与截止时间

1. 客户端挂载可读一次`getVoices()`并监听`voiceschanged`更新能力；这不触发朗读。按钮点击时已有适用voice，就在当前手势回调同步调用`speak()`，前面不能await请求、动态导入或nextTick。
2. 点击时尚无voice，最多等待1.5秒；重复voiceschanged不延长本次截止时间。随后尝试一次；若手势已丢失，由现有原位重试恢复。不通过静音预播放绕过限制。
3. 调用speak到start最多2秒；真实start到end最多12秒。去掉原先词条2.5秒和录音2.5秒，禁止把它们作为“构思”或假加载动画保留。设备已有voice时无需等待1.5秒。
4. 单页始终只有一条活动utterance。重播/换词先使旧令牌失效并取消旧占用，再开始新尝试；控制器保留utterance强引用到终态。迟到事件不能修改新词或被240ms退场DOM带回。
5. 默认优先实际设备默认英语声音，否则稳定选一个英语声音。同一口音多个voice只选代表项，不展示全设备声音目录；地区未知保持中性。只有实际可用选项才形成口音菜单，不固定显示UK/US。
6. 已选口音失效继续按R3+TA1：唯一替代也须明确选择；无替代则失败。单个选项的普通状态仍不显示来源文字。

不存在服务端幂等键、事务、分页、写入或后台重试。每次用户点击是新意图；声音枚举可变，不永久保存voiceURI或账号偏好。

## 与上一版的差异及验证

移除FreeDictionary适配器、第三方JSON、录音URL/许可字段、fetch Blob/Audio生命周期、录音缓存和词典超时/回退状态。不为本功能添加dictionary域名的connect-src或blob媒体策略；保持已有其他功能策略，不能据此全局删CSP来源。

前端仍保留单页协调器、speech端口、控件、三处生命周期及TA1口音交互。已有词典fixture验收条目应撤下并明确原因；新增/保留声音延迟、无英语、手势、超时、取消和晚事件测试。最终UAT不用mock；确定性端口测试可以使用fake voice/clock，但不得作为真实发声证明。

当前本机Chrome探测结果见[后端补充](../backend-followup.md)。其他设备、最长等待后的手势与用户可听性仍未通过。产品/设计/前端的受影响源由CR-316接收，不因本合同自动算已同步。
