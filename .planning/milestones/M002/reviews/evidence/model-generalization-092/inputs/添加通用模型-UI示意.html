添加通用模型 · UI 示意

对齐 MiMo Desktop「设置 → 模型 / Providers」的 BYOK 自定义模型能力。三张示意：列表页、添加表单、Composer 模型选择器。实现细节以《添加通用模型-功能实现Prompt.md》为准。

实现要点（与 Prompt 对应）

  • 字段命名严格使用 baseURL / apiKey，适配器 @ai-sdk/openai-compatible 或 @ai-sdk/anthropic。
  • Base URL 原样保存，不自动补全或归一化 /v1；Anthropic 模式不要填完整 /v1/messages。
  • 列表与日志中 API Key 一律脱敏；配置写入全局 ~/.config/mimocode/mimocode.jsonc。
  • 保存成功后合并写入 model.json 的 recent（置顶、去重、上限 10），保留 favorite / variant。
  • 「仅添加」不改顶层 model；「设为默认 / 保存并使用」才写默认选择。
